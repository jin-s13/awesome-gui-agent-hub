benchmark

GUI/web/mobile/OS automation datasets, environments, tasks, metrics, and benchmarks

61 方法质量 99 近期性 39 可复现性 47 主题相关性

文献综述归纳

研究路线

真实世界与交互特定的GUI任务和环境构建

为桌面、动态短视频、拖拽和视频引导GUI任务提供共享任务、数据集与环境，使不同代理实现能在具体交互表面上比较。

尚未覆盖：覆盖范围受限于特定平台或交互类型；动态界面的观察控制与跨平台泛化仍未验证。
细粒度与可靠性导向的评价指标

在总分之外检验子目标完成、信息效率、不确定性排序和交互特定正确性。

尚未覆盖：代理指标可能偏离下游用户决策；不确定性与校准排序跨模型层级或接口迁移较弱，并在分布偏移下退化。
通过任务合成、技能表示与弱监督改进代理

用可验证生成任务、多模态技能工件或未标注截图定位来规模化训练或推理，提升基准表现与数据效率。

尚未覆盖：证据通常绑定在选定基准上；实现与算力预算稳定性、以及更广泛的多步部署尚未充分建立。
可比基线与报告规范

使用前沿开源与闭源VLM代理、固定基准和公开工件使结果可审计。

尚未覆盖：代码、数据集和局限性报告不均衡；缺失工件或基线细节构成验证缺口，而非证明不存在。

研究共性

  • 基准越来越多地在总体成功率之外评价子目标完成、成本-准确性、不确定性或交互特定正确性。
  • 前沿VLM代理在动态、多应用或需要观察控制的任务上仍低于人类水平。
  • 多模态技能、生成RL任务和弱监督等表示与训练干预相比简单基线带来显著提升。
  • 结论常以单一平台或模型类别为条件；跨平台和跨模型稳定性尚未得到证明。

关键差异

  • 评价目标不同：确定性多检查点评分、动态信息流上的成本-准确性、后验不确定性排序和拖拽交互准确率。
  • 监督与改进策略不同：未标注截图弱监督定位、可验证生成任务配合在线RL、以及保留视觉图形的多模态技能工件。
  • 交互表面不同：真实macOS桌面的GUI与CLI、短视频浏览器环境、拖拽手势、视频引导任务和单步GUI定位。
  • 部署体制不同：开源与闭源模型访问、模拟与真实OS/浏览器设置、单步与多步轨迹。

开放问题

  • 细粒度指标能在多大程度上对齐用户在真实GUI工作流中真正关心的下游决策？
  • 动态界面的观察控制能否在不只过拟合于短视频等单一平台的情况下被基准化和改进？
  • 不确定性或校准能否跨模型层级和接口迁移，还是必须针对每个部署目标重新估计？
  • 当代码和数据集可用性不均衡时，基准结论在不同实现、算力预算和缺失工件下是否稳定？

method

GUI agent models, planning, grounding, action prediction, training, or reasoning methods

60 方法质量 99 近期性 39 可复现性 45 主题相关性

文献综述归纳

研究路线

面向异构动作接口的基准与评估设计

把GUI评估从静态点击扩展到拖拽、GUI+CLI混合和动态短视频界面，提供多检查点或成本准确性指标。

尚未覆盖：覆盖范围集中在特定平台，人类基线深度不一，且若干局限字段缺失，跨界面泛化仍未验证。
可扩展训练与任务合成方法

通过无标注截图弱监督、可验证在线强化学习任务生成和上下文动作监督微调，缓解数据稀缺与样本效率问题。

尚未覆盖：任务合成、rollout分配、上下文管理或关键帧提取的增益未与系统其它选择隔离；广泛迁移尚未显示。
上下文、观察与规划接口方法

通过主动上下文管理提升长时移动任务完成度，并将动态界面失败解释为过度观察或观察不足。

尚未覆盖：智能体仍缺乏对动态屏幕的显式观察控制，证据仅限于特定移动或短视频设置。
不确定性与可靠性协议

对GUI落地后验不确定性方法做基准测试，测量排序迁移，并构造用于空间安全的共形点击区域。

尚未覆盖：仅覆盖单步可执行落地，跨模型和跨接口迁移弱，分布偏移下覆盖度下降。

研究共性

  • 研究正在超越纯点击任务，强调拖拽、GUI+CLI、动态内容等更丰富的动作与观察接口。
  • 仅看Pass@1不够，需要子目标完成度、信息效率或不确定性排序等更细粒度信号。
  • 任务相关训练或弱监督数据可以改善GUI落地和长时任务性能。
  • 方法增益常源自技能库、上下文管理或关键帧提取等配套组件，而非单一模型或框架选择。

关键差异

  • 评测粒度不一致：单步可执行落地与长时任务成功率难以直接比较。
  • 动作空间侧重不同：拖拽交互、GUI+CLI混合、动态观察控制和视频引导关键帧选择各有侧重。
  • 监督信号不同：弱监督视觉落地、可验证在线强化学习和上下文动作监督微调并存。
  • 指标不同：Pass@1与子目标检查、成本准确性、不确定性排序迁移和共形覆盖度没有统一标准。

开放问题

  • 现有方法能否跨平台、跨接口、跨模型类稳定迁移，而不只是在特定基准族内有效？
  • 动态屏幕代理如何获得观察控制，避免过度观察与观察不足？
  • 后验不确定性方法在单步落地基准上有效，但在多步轨迹和分布偏移下是否仍保持校准？
  • 如何隔离技能库、rollout分配、上下文动作和关键帧提取等组件的净贡献？
  • 多个高排名工作未披露局限性、代码或数据，失败边界与可复现性如何验证？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

61 方法质量 99 近期性 39 可复现性 47 主题相关性

文献综述归纳

研究路线

基准与任务抽象：MacAgentBench、LivingScreen、DragOn

将评测从静态点击式 GUI 扩展到多应用桌面 GUI+CLI、动态短视频界面和拖拽式交互原语。

尚未覆盖：这些套件向其他界面的迁移尚未得到证明；指标与套件绑定，动态观察控制仍是能力缺口。
可验证与弱监督训练数据扩展：ScaleCUA、GUICrafter

通过生成可验证任务和使用未标注截图进行视觉定位，减少人工标注或支撑在线 RL。

尚未覆盖：证据主要集中在 OSWorld 与 ScienceBoard 或有限对比；向动态、拖拽、移动和多应用场景的迁移尚未确立。
技能与上下文增强：VISUALSKILL、MemGUI-Agent

提供多模态程序性技能工件和紧凑、主动管理的长时域上下文，以改善动作定位和工作流状态验证。

尚未覆盖：在已报告 CLI/移动基准之外的泛化有限；工件构建与上下文动作训练假设需要更广泛验证。
可靠性与不确定性框架：Argus

对 GUI grounding 事后不确定性量化进行基准测试，并引入用于空间安全的共形点击区域。

尚未覆盖：仅限于单步 grounding；UQ 排名跨模型层级和接口迁移较弱，共形覆盖在分布偏移下下降。

研究共性

  • 当前 GUI 代理研究正在转向更真实的任务抽象与更细粒度的评估信号，而非只看最终任务成功。
  • 前沿 VLM 在动态观察控制、拖拽交互、长时域上下文和不确定性校准的可靠性方面仍有明显差距。
  • 技能条件、弱监督、在线 RL 和显式上下文管理等目标干预带来可测量的提升。
  • 许多结果在较窄的基准族上报告，跨基准与部署迁移证据仍然不足。

关键差异

  • 评测目标不同：静态多应用桌面任务完成、动态短视频成本准确性、拖拽交互成功、移动长时域完成、单步 grounding 不确定性。
  • 监督与训练策略不同：可验证在线 RL、基于截图的弱监督、推理时多模态技能检索、有监督上下文动作管理。
  • 交互模式重点不同：GUI+CLI 组合、拖拽原语、动态界面观察、长时域移动动作历史分别被不同路线强调。
  • 可靠性框架不同：观察控制、上下文压缩、事后不确定性校准被作为不同问题处理，证据类型也不同。

开放问题

  • 在一个 GUI 任务族上训练或调优的代理，能否在没有目标任务重标注或重排序的情况下迁移到动态、拖拽、长时域和多应用任务？
  • 什么样的形式化任务抽象能解释已观察到的过度观察、观察不足和跨层级不确定性排名弱等失败模式？
  • 应如何表示和学习观察控制，使代理在任务准确性与信息成本之间取得平衡？
  • 保留视觉或结构化上下文是否能在界面变化下提高长时域可靠性，而不带来过高成本？
  • GUI grounding 不确定性能否跨模型类别和接口迁移，并覆盖多步轨迹？

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

58 方法质量 99 近期性 39 可复现性 44 主题相关性

文献综述归纳

研究路线

端到端在线强化学习训练栈，例如OpenForgeRL和OpenWebRL

在真实浏览器或harness原生环境中运行多轮智能体训练，将模型调用和回滚转化为策略优化数据。

尚未覆盖：强化学习后错误恢复仍弱；harness设计影响可训练性；跨部署与工件可复现性仍缺乏独立证据。
可回放记忆与多模态技能服务，例如EchoPath和VISUALSKILL

将已验证轨迹或应用相关的视觉/文本知识缓存为可调用记忆或技能，降低重复规划成本并改善UI元素识别。

尚未覆盖：适用性检查会拒绝模糊或不兼容步骤；跨应用、运行时状态及独立工件的泛化尚未确立。
步骤级诊断与安全评测，例如Desktop-Delta Bench和领域条件安全审计

隔离GUI过渡理解、状态/来源跟踪和对抗提示注入抵抗，而非只看总体任务成功率。

尚未覆盖：离线评测无法捕捉异步实时动态；当前范围限于Linux/桌面或选定的浏览器/编码领域；优化攻击字符串未被复现。
低标注与替代生成式GUI策略学习，例如GUICrafter和LLaDA-UI

通过未标注截图降低标注数据需求，并探索块级扩散解码用于多模态GUI智能体。

尚未覆盖：局限性披露较少；与实时系统栈的集成及跨平台独立复现仍未解决。

研究共性

  • 多个系统将已验证交互轨迹或应用特定知识视为可复用工件，以降低token/时间成本并改善grounding。
  • 若干工作用少量精选或验证数据结合可扩展环境，如真实网页、harness容器或未标注截图，来训练或适配智能体。
  • 评测越来越多地加入最终任务成功之外的诊断层，包括过渡排序、动作载荷识别、状态验证或对抗攻击成功率。

关键差异

  • 训练信号不同：在线多轮强化学习使用实时回滚，弱监督使用未标注截图，监督微调使用多模态技能数据。
  • 评测目标不同：一条路线衡量端到端基准分数，另一条隔离步骤级过渡理解，第三条测试跨领域对抗安全。
  • 交互模式不同：可回放记忆假设确定性适用并拒绝模糊步骤，而实时强化学习假设有状态、异步的浏览器或harness进程。
  • 工件表示不同：多模态技能保留图形以辅助视觉定位，而可调用参数化记忆存储前置条件与已验证GUI证据。

开放问题

  • 哪些harness或环境属性最影响可训练性和训练后的错误恢复？
  • 离线步骤级诊断能否扩展到异步实时GUI动态，同时保持可控性？
  • 浏览器领域的安全加固在编码或其他工具使用领域中的迁移效果如何？
  • 基于工件的记忆与技能系统在多样应用、操作系统和独立复现部署下是否仍然可靠？

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

64 方法质量 99 近期性 37 可复现性 50 主题相关性

文献综述归纳

研究路线

真实操作系统桌面代理基准测试

在真实 macOS 桌面上通过 GUI+CLI 任务和细粒度子目标评分测量多应用计算机使用能力。

尚未覆盖：超出已报告框架和模型的迁移未验证；局限性与工件可用性信息大多缺失。
面向特定应用的多模态技能库

提供分层文本加视觉技能工件，用于改善 UI 元素识别和工作流状态验证。

尚未覆盖：证据限于 CUA-World 和 OSExpert-Eval 的单一代理栈；跨应用迁移与技能维护仍开放。
动态与视频引导界面grounding

评测代理在动作间变化的界面以及视频引导任务上的表现，并通过关键帧提取降低视觉输入负担。

尚未覆盖：当前模型缺乏观察控制；收益能否迁移到已测平台之外的真实动态 UI 尚不清楚。
超越点击的交互原语覆盖，尤其是拖拽grounding

为拖拽式 GUI 交互创建评测和训练数据，涵盖文本高亮、单元格选择、缩放和滑块操作。

尚未覆盖：除保留测试集和微调单一 VLM 外，下游生产影响未展示；局限性细节缺失。

研究共性

  • 本主题的 GUI 代理研究围绕应用任务基准展开，并采用确定性或规则式评分。
  • 视觉grounding、UI 元素识别和工作流状态验证仍是桌面、网页和动态平台的核心瓶颈。
  • 细粒度评测（如子目标检查点或成本-准确率）能揭示总体成功率掩盖的能力差异。
  • 复用经验证的知识或轨迹（技能工件或可重放记忆）可提高准确性和/或降低 token 与时间成本。
  • 当前模型在需要管理动态界面观察或执行拖拽等低层交互时最常失败。

关键差异

  • 基准范围差异明显：macOS 桌面多应用任务、短视频动态界面、视频引导任务、拖拽交互和跨平台 grounding 或导航套件各不相同。
  • 评测目标不同：最终任务成功、细粒度子目标完成、成本-准确率效率、grounding 准确率和执行效率被不同工作优先。
  • 改进策略不同：部分工作提供外部技能库或记忆，部分工作训练新策略，例如扩散视觉语言代理。
  • 交互假设不同：部分假设点击/输入或 GUI+CLI，部分显式建模拖拽或动作间动态视觉观察。
  • 复用形式不同：层级主题检索、带屏幕检查的状态机重放和参数控制的可调用记忆使用不同的护栏与回退行为。

开放问题

  • 当前应用特定基准在 OS 版本、应用更新和未见工作流上的迁移能力如何，尤其在代码和工件未完全公开时？
  • 何种观察控制策略能让代理在动态或短视频等界面达到人类水平的成本-准确率？
  • 拖拽grounding 等低层交互数据集的收益能否从微调模型迁移到真实计算机使用任务？
  • 应用界面变化时，多模态技能库如何保持更新？需要多少维护成本？
  • 在什么条件下，已验证轨迹重放能安全泛化，而不依赖过时屏幕或重新规划？

survey

Surveys, taxonomies, tutorials, position papers, or roadmap papers for GUI agents

55 方法质量 99 近期性 37 可复现性 42 主题相关性

文献综述归纳

研究路线

GUI智能体能力的分类体系与路线图综合

把碎片化的GUI智能体研究组织为视频引导任务、长时程移动控制、基础定位不确定性、安全和数据生成等方向。

尚未覆盖：证据包中缺少显式综述或系统分类；综合只能从基准和方法论文中推断，覆盖范围与筛选标准没有得到证据支撑。
跨GUI基准与协议的对比评测综合

展示屏蔽线索、系统提示变化、数据集偏移和接口差异如何影响跨视觉语言模型、GUI定位、网页和移动任务的结论。

尚未覆盖：单步与多步设置、闭源内部状态不可访问以及工件披露不一致，限制了可比性。
可靠性、安全与部署的开放问题映射

把不确定性量化迁移、领域条件安全、长时程上下文和自主评估器噪声等实证结果转化为研究缺口。

尚未覆盖：缺口优先级没有证据；多步不确定性量化、优化攻击和真实世界信誉线索边界仍未解决。
面向可扩展GUI智能体训练的任务与演示生成

创建可验证任务、人类录屏教程和合成上下文管理演示，用于监督学习和强化学习。
