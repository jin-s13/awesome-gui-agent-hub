benchmark

GUI/web/mobile/OS automation datasets, environments, tasks, metrics, and benchmarks

60 方法质量 100 近期性 40 可复现性 42 主题相关性

文献综述归纳

研究路线

真实桌面与OS任务基准

构建共享交互任务与确定性或可验证检查，测试跨应用GUI/CLI完成能力。

尚未覆盖：动态内容覆盖以及超出特定应用和OS版本后的跨平台、跨应用泛化尚未稳定验证。
动态与视频引导界面基准

评测操作之间内容变化的界面，考察选择性观察或关键帧理解，并纳入效率约束。

尚未覆盖：当前覆盖集中在短视频平台场景；尚无模型达到人类水平的成本-准确性或观察控制。
细粒度指标、观察诊断与不确定性量化

在pass@1之外揭示子目标完成、成本-准确性、过度/不足观察和GUI grounding不确定性差异。

尚未覆盖：与下游多步可靠性之间的代理指标一致性仍不明确；不确定性排名跨模型层级和接口迁移具有选择性。
基准驱动的训练、harness与技能改进

通过可验证任务合成、未标注截图、多模态技能工件或harness优化改进冻结或RL训练代理。

尚未覆盖：跨实现、算力预算、重复运行稳定性以及训练/评估污染控制仍缺少完整验证。

研究共性

  • 真实交互环境中的确定性或可验证任务检查正在替代纯静态或合成网页评测。
  • 总分不足以评价代理：细粒度子目标检查点、成本-准确性、观察效率和不确定性度量能揭示不同行为。
  • 冻结模型可通过技能记忆、执行harness或训练课程显著改进，而非仅依靠模型扩展。
  • 当前代理在动态或真实计算机使用任务上仍低于人类水平，常因观察控制或grounding可靠性不足。

关键差异

  • 评测目标不同：静态桌面任务完成、动态短视频界面、视频引导任务或单步GUI grounding。
  • 监督来源不同：可验证奖励/任务合成、未标注截图、人工编写的多模态技能或重复运行证据。
  • 主要指标不同：pass@1任务成功、细粒度检查点、成本-准确性，或不确定性校准与conformal覆盖。
  • 部署场景不同：macOS桌面、Windows桌面、基于浏览器的短视频平台和跨平台harness迁移。

开放问题

  • 哪些诊断指标最能预测下游用户信任和多步任务可靠性，仍缺少跨基准验证。
  • 不确定性量化与观察控制发现能否跨开源/闭源模型层级和接口迁移，还是必须进行目标特定重新评估？
  • 基准驱动的提升有多少来自训练/评估重叠、特定harness实现或技能库，而非通用代理能力？
  • 动态界面结果能否推广到持续变化的OS、web和移动端自动化场景，仍是开放问题。

method

GUI agent models, planning, grounding, action prediction, training, or reasoning methods

59 方法质量 100 近期性 40 可复现性 41 主题相关性

文献综述归纳

研究路线

真实 GUI 智能体基准与交互覆盖

将评测从静态点击屏幕扩展至桌面任务、动态短视频、拖拽操作和视频引导操作，并加入细粒度子目标、成本-准确性等指标。

尚未覆盖：覆盖性能否跨操作系统、应用与动态界面族泛化仍不明确；现有基准受限于所选平台，并常局限于特定任务或轨迹设置。
数据高效与自改进的 GUI 训练方法

通过可验证任务合成与在线 RL、未标注截图弱监督、任务驱动关键帧提取或证据驱动的 harness 演化，降低标注和样本成本。

尚未覆盖：在报告保留套件之外的迁移尚未确立；收益有多少来自训练信号而非 harness、技能库或 rollout 分配仍不清晰。
GUI grounding 的可靠性与不确定性评测

测量模型置信度、空间定位和观察控制，并通过跨模型不确定性排序与共形点击区域揭示校准问题。

尚未覆盖：多步轨迹的不确定性尚未覆盖；排序与覆盖在校准-测试或界面分布漂移下退化，限制部署鲁棒性。

研究共性

  • 评测正从静态点击屏幕转向动态、多界面和细粒度任务设置，测量子目标完成、信息效率或 grounding 可靠性。
  • 前沿视觉语言代理在动态或成本敏感设置中仍低于人类水平；失败常源自 grounding、观察控制或界面覆盖，而非仅动作正确性。
  • 方法越来越多使用弱监督、可验证合成任务、关键帧选择或 harness 优化，以在少量人工标注或冻结模型条件下提升 GUI 智能体。

关键差异

  • 评测目标与交互模式不同：桌面 GUI+CLI 任务、动态短视频观察、视频引导智能体任务、拖拽操作和单步 grounding。
  • 改进策略不同：有的通过可验证合成任务进行在线 RL，有的使用未标注截图弱监督，有的优化冻结执行框架或技能库，有的评测不确定性或关键帧提取。
  • 主要指标不同：细粒度子目标的 Pass@1、成本-准确性或信息效率、不确定性排序与共形覆盖，或拖拽任务成功率。
  • 证据范围不同：一些报告多轮迁移到另一个基准，另一些只覆盖单一平台、单步 grounding 或选定界面类型。

开放问题

  • 动态界面下的观察控制发现能否迁移到桌面、短视频和视频引导任务？
  • 合成可验证任务、未标注截图或 harness 编辑证据中，哪种监督信号能更稳健地泛化到报告基准之外？
  • 如何在开源与闭源视觉语言代理之间、以及界面与分布漂移下维持不确定性校准？
  • 细粒度指标是否真正隔离了模型或方法贡献与框架、技能库、harness、rollout 分配的影响？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

59 方法质量 100 近期性 40 可复现性 41 主题相关性

文献综述归纳

研究路线

可执行的GUI工作流任务抽象

将静态点击评测扩展到多应用桌面任务和动态界面条件的形式化。

尚未覆盖：抽象能否跨平台迁移；动态设置下是否真正暴露观察控制机制。
基础定位的可靠性与不确定性量化

在不同VLM接口下度量UI元素定位的置信度校准和安全边界。

尚未覆盖：证据限于单步定位；跨模型、跨接口和分布偏移下的迁移仍然较弱。
冻结模型的外部技能与执行框架适应

在不重训模型的情况下，通过多模态技能或执行框架证据回路改善GUI智能体。

尚未覆盖：对未见过环境的迁移，以及对特定框架和模型族的依赖尚不明确。
可验证任务合成与数据高效训练

用可验证任务和未标注截图扩展在线RL或弱监督，降低人工标注成本。

尚未覆盖：真实失败模式、长程依赖，以及合成任务与自然任务分布之间的差距。

研究共性

  • 近期证据收敛到可执行、基于规则或可验证的评估，作为GUI智能体声明的基础。
  • 细粒度指标揭示了平均任务成功率隐藏的差异，尤其是子目标完成、成本-准确率和不确定性排序。
  • 技能和执行框架等外部适应工件可以改善冻结模型，将关注点从权重转向交互层设计。
  • 视觉定位和观察控制被视为动态多模态GUI任务的核心瓶颈。
  • 未标注或合成训练信号越来越多地被用于降低人工标注成本。

关键差异

  • 一方通过在线RL或弱监督改变模型权重，另一方保持权重冻结并优化技能或执行框架。
  • 文本与多模态技能表示存在差异：保留视觉图形的技能在识别UI元素和工作流验证上优于纯文本技能。
  • 评测目标不同：端到端任务完成、单步定位不确定性和动态观察下的信息效率并存。
  • 监督假设不同：可验证任务合成、未标注截图弱监督和小规模高质量标注校准各成路线。
  • 动作空间覆盖不同：点击、拖拽、GUI+CLI与动态屏幕形成不同的边界条件。
  • 部署环境从桌面macOS到浏览器动态平台和Docker基准套件不等，其失败模式未必共享。

开放问题

  • 动态屏幕智能体如何学会观察控制，而不是对变化内容过度观察或观察不足？
  • 技能或执行框架层面的提升能否迁移到源环境和模型族之外？
  • 不确定性排序能否在跨模型类别和接口偏移下保持稳健，而无需目标特定重排？
  • 可验证任务合成是否覆盖真实长程失败模式，还是只是过拟合到可被求解器检查的工件？
  • 如何把若干顶部论文中缺失的局限性和可复现性证据纳入评估？

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

59 方法质量 99 近期性 40 可复现性 43 主题相关性

文献综述归纳

研究路线

端到端多模态GUI/计算机使用智能体与统一动作空间

将视觉定位、GUI交互和代码执行合并为单一可训练策略，用于桌面和移动计算机使用任务。

尚未覆盖：已报告基准之外的跨平台与分布外泛化，以及学习到的GUI/代码协调在部署中的长期稳定性尚缺乏证据。
数据高效与弱监督GUI智能体训练

通过未标注截图学习视觉定位，再用少量监督或强化学习校准，降低对昂贵人工标注的依赖。

尚未覆盖：跨出已报告GUI设置后的迁移，以及未知应用所需的最少标注量仍未明确。
轻量低延迟动作策略

通过无解码器潜空间评分或块级扩散避免逐token VLM解码，提高推理速度与参数效率。

尚未覆盖：准确率仍落后于更大微调VLM，且证据主要限于分布内或单一基准评测。
Harness原生训练与编排框架

无需重写harness即可对基于复杂多进程推理harness的智能体进行强化学习和容器化回滚编排。

尚未覆盖：训练后错误恢复仍较弱，harness设计显著影响可训练性；独立复现与部署证据不足。

研究共性

  • 视觉语言grounding被视为计算机使用和GUI智能体能力的核心组件。
  • GUI/计算机使用基准上的成功率是常见证据信号，通常配合基线与消融实验。
  • 在原始视觉/文本策略之外加入多模态技能、代码动作、潜在候选评分或RL编排等结构，被用于提升成功率或推理效率。
  • 预训练后进行监督微调或强化学习是对齐智能体计算机使用行为的共享方法。
  • 即使任务完成率较高，错误恢复和个性化能力仍被识别为薄弱点。

关键差异

  • 动作表示不同：显式GUI操作、代码执行、潜在候选评分或块级扩散生成。
  • 监督信号不同：未标注截图弱监督、混合应用-工件监督、在线RL或harness记录回滚。
  • 推理模式不同：自回归VLM解码、无解码器潜在评分和块级扩散在速度与准确率之间做不同权衡。
  • 部署场景不同：移动、桌面、网页和harness专用编排被分别评测，跨场景迁移尚不清晰。
  • 评测目标不同：grounding/导航、端到端任务成功、恢复一致性或个性化诊断，不能互换作为证据。

开放问题

  • 轻量低延迟策略如何在保持速度和参数效率优势的同时缩小准确率差距？
  • 什么恢复机制能让智能体在无需昂贵重置或长时程重放的情况下利用潜在恢复能力？
  • 统一GUI/代码动作空间在操作系统、应用集和部署容器之间的迁移表现如何？
  • 弱监督GUI智能体需要多少监督和环境覆盖才能泛化到已报告基准之外的场景？
  • 个性化和记忆机制能否在不降低非个性化任务性能的情况下改善偏好敏感任务？

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

62 方法质量 99 近期性 39 可复现性 44 主题相关性

文献综述归纳

研究路线

真实桌面 OS 任务评测

在多应用 GUI 与 CLI 任务上，用细粒度子目标评分衡量跨框架、跨模型的智能体行为。

尚未覆盖：未见局限性说明；测试桌面 OS 之外的泛化、长程可靠性以及对系统或应用更新的敏感性尚待验证。
动态与交互特定 GUI 任务评测

在动态短视频界面和拖拽交互上测试智能体，暴露观察控制和交互定位缺口。

尚未覆盖：平台和领域范围有限，代码与数据工件可用性不一致；向其他动态界面或真实用户工作流的迁移仍开放。
多模态技能与重放记忆

通过分层多模态技能检索提升准确率，并通过带屏幕检查回退的状态机重放降低重复任务延迟。

尚未覆盖：多数论文缺少局限性说明；技能构建成本、界面漂移下的维护和测试外的回退鲁棒性需证据支持。
可扩展网页环境与轨迹生成

从真实 URL 重建可复用、有源头的网页环境和轨迹，减少逐站点人工实现并改善保真度与微调收益。

尚未覆盖：每个站点初始需要设置与授权；已审计领域以外的保真度和真实网站部署安全仍需验证。

研究共性

  • 评测正在从静态网页或点击任务扩展到更丰富的真实应用界面，如多应用桌面、拖拽交互、动态信息和 GUI+CLI 工作流。
  • 细粒度过程指标如子目标完成、信息成本准确率、延迟和保真度，能揭示通过率掩盖的智能体弱点。
  • 为智能体提供可复用环境工件、多模态技能或训练轨迹可改善任务成功或效率。
  • 当前前沿模型在这些应用基准上仍暴露观察控制、拖拽定位和跨应用泛化不足。

关键差异

  • 智能体知识的表示方式不同：多模态技能库、编译式状态机程序、基于扩散的视觉语言策略、合成轨迹微调。
  • 改进策略不同：推理时检索或重放而不更新模型权重，与基于拖拽、网页或 GUI 轨迹的微调。
  • 评测目标不同：分别优化确定性任务完成、信息成本准确率、重复任务速度、环境保真度和视频引导接地。
  • 部署场景不同：真实桌面操作系统、短视频浏览器环境、从真实 URL 重建的网页环境以及移动/桌面/网页导航套件。

开放问题

  • 从合成拖拽、网页或视频轨迹中获得的提升能否迁移到真实专业工具、OS 更新和未见应用布局？
  • GUI 智能体如何学习观察控制，以避免动态界面中的过度观察和观察不足？
  • 技能库和重放程序在界面漂移或用户目标变化下会如何退化，维护成本有多大？
  • 哪些指标如准确率、信息成本准确率、延迟、保真度或子目标完成应定义跨应用领域的部署就绪性？
  • 许多高排名论文缺少可见的局限性说明或一致的工件信号；这些验证缺口是否隐藏系统性失败模式或可复现性限制？

survey

Surveys, taxonomies, tutorials, position papers, or roadmap papers for GUI agents

55 方法质量 99 近期性 38 可复现性 39 主题相关性

文献综述归纳

研究路线

分类与路线图综合

将碎片化的GUI智能体方向整理为分类、基准和开放缺口。

尚未覆盖：证据包中排名靠前的多是方法与基准论文，而非真正综述，系统覆盖与优先级证据缺失。
可验证任务合成与环境监督

生成可扩展的GUI标注或可验证任务数据，用于训练和评测。

尚未覆盖：合成或桌面设置之外的迁移，以及不同界面下结果兼容性尚未建立。
执行框架与上下文管理

通过编辑执行框架或主动压缩上下文，提升长程或冻结模型智能体的表现。

尚未覆盖：依赖重复运行证据或轨迹标注；跨部署边界与失败覆盖仍不明确。
高效感知与动作评分

降低GUI动作选择中的视频/关键帧或token解码开销。

尚未覆盖：精度低于微调VLM基线，评测多为AndroidControl或视频基准；分布外行为未验证。

研究共性

  • 多数研究在任务完成或定位基准上评测，并相对强VLM或智能体基线报告提升。
  • 普遍利用截图、无障碍树、动作结果、重复运行等交互证据来监督、诊断或评分智能体行为。
  • 多种方法不再仅靠扩大模型规模，而是围绕骨干优化数据、上下文、执行框架、关键帧或动作评分。
  • 可靠性、校准与长程行为正成为第一类评测目标，而非仅看单步准确率。

关键差异

  • 动作接口不同：潜空间评分、解码动作文本、上下文管理动作、关键帧选择与可执行框架编辑之间差异明显，难以直接比较。
  • 监督来源不同：可验证合成任务、可控桌面环境的密集标注、重复任务运行、受控掩码欺诈证据对应不同假设。
  • 评测目标不同：单步定位不确定性、长程任务成功、移动/桌面/Windows任务完成、视频引导任务与网页欺诈判断并不等价。
  • 模型部署假设不同：有的冻结骨干并在周围优化，有的微调VLM参数，有的完全移除解码器，导致精度与延迟权衡不一致。
