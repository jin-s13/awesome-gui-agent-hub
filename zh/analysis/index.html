benchmark

GUI/web/mobile/OS automation datasets, environments, tasks, metrics, and benchmarks

61 方法质量 99 近期性 38 可复现性 46 主题相关性

文献综述归纳

研究路线

真实GUI/计算机使用任务套件与数据集（如 MacAgentBench、LivingScreen、DragOn、VG-GUIBench）

构建共享任务和环境，使桌面、浏览器、动态内容、视频引导和拖拽交互中的代理能力具有可比性。

尚未覆盖：这些任务分布是否覆盖长程多应用工作流、未见过的OS/应用配置及动态界面变体；部分套件在证据中缺少完整局限或工件细节。
细粒度指标与压力测试设计（如多检查点评分、成本-准确性、不确定性量化、拖拽定位评测）

在总体成功率之外检验子目标完成、观察效率、选择性不确定性排名迁移、共形点击覆盖和交互类型定位。

尚未覆盖：这些诊断指标与下游部署可靠性的对齐尚未建立；不确定性排名跨模型类别和接口迁移较弱，分布偏移下覆盖率下降。
基准驱动的基线、训练与报告（如 VISUALSKILL、ScaleCUA、GUICrafter 使用 OSWorld、ScienceBoard、CUA-World、OSExpert-Eval）

通过共享基准分数、规则或可验证奖励和共同基线，使技能库、在线RL和弱监督的进展可比。

尚未覆盖：基准结论在实现、框架和算力预算下的稳定性大多未被检验；若干系统报告强结果，但证据中未显示完整工件或报告细节。

研究共性

  • 领域一致认为仅看总体任务成功率不足；细粒度子目标、效率或诊断指标能揭示模型差异。
  • 更偏好真实、应用驱动的环境，并用规则基线或人工参考进行评分。
  • 前沿视觉语言代理在动态或长程计算机使用任务上仍低于可靠的人类水平，尤其在观察控制和不确定性迁移方面。

关键差异

  • 交互范围：有的评估静态桌面或拖拽动作，有的针对动态短视频/实时界面或视频引导序列。
  • 监督与数据：有的使用可验证规则任务合成，有的使用海量未标注截图，有的使用多模态技能工件。
  • 评测目标：有的关注任务成功和子目标进展，有的关注观察成本-准确性、单步定位不确定性或拖拽完成情况。

开放问题

  • 当前GUI/计算机使用基准任务能否迁移到未见过的OS/应用配置和长程多应用工作流？
  • 当不确定性排名跨模型类别和接口迁移较弱时，哪些细粒度指标最能预测部署可靠性？
  • 可验证任务合成和弱监督流水线能否在不同框架和算力预算下产生稳定结论，而不过拟合基准特定奖励信号？

method

GUI agent models, planning, grounding, action prediction, training, or reasoning methods

60 方法质量 99 近期性 38 可复现性 45 主题相关性

文献综述归纳

研究路线

屏幕接地与交互空间基准

将可执行的GUI评测从静态点击扩展到拖拽、动态短视频、macOS GUI+CLI以及视频引导交互。

尚未覆盖：超出所报告平台或交互类型之外的泛化；动态内容下的观察控制仍未解决。
训练与数据规模化方法

通过无标注截图弱监督或带可验证任务合成的在线RL，降低人工标注依赖并扩大任务覆盖。

尚未覆盖：报告增益是否来自学习算法、任务合成管道、采样策略或基线实现选择尚不明确。
长时域上下文与规划方法

在长时域移动GUI轨迹中，通过将上下文管理作为策略动作并采用结构化字段来保持关键信息。

尚未覆盖：跨基准证据仍然较窄；上下文管理动作是否能迁移到已训练基准族之外尚未确证。
不确定性与评测协议方法

将模型排名与细粒度步骤完成指标分开，并通过后验不确定性方法量化接地置信度以支持更安全的动作预测。

尚未覆盖：现有不确定性基准止步于单步接地；多步轨迹风险和跨模型/跨接口弱迁移未覆盖。

研究共性

  • GUI智能体被一致地框架化为视觉语言动作接地：模型观察屏幕或视频上下文并输出可执行界面动作。
  • 评测正向更丰富的交互覆盖和更细粒度评分演进，包括子目标完成、成本-准确率、拖拽、动态内容和多应用GUI+CLI任务。
  • 训练创新旨在通过弱监督、课程学习和可验证在线RL降低人工标注成本或增加任务覆盖。
  • 报告的提升通常依赖多个组件，因此模型、策略、数据和评测效应的分离仍是证据缺口。

关键差异

  • 单步可执行接地在不确定性工作中被作为安全计算机使用的代理，而其他工作评测长时域任务成功，导致对智能体能力的定义不同。
  • 若干基准假设静态屏幕或点击/拖拽接口，另有工作关注动作之间发生变化的动态屏幕内容。
  • 监督策略存在差异：来自无标注截图的弱监督视觉接地、标注轨迹SFT，以及带可验证任务合成的在线RL。
  • 上下文处理方式不同：一些智能体将被动历史积累替换为主动上下文管理，而动态界面工作关注观察控制而非记忆策略。
  • 不确定性迁移在同一模型家族内较稳定，但在开闭源模型层级间较弱，因此部署环境不同会带来不同校准需求。

开放问题

  • 在某一交互类型上训练或评测的智能体，有哪些因素使其能迁移到拖拽、动态、多应用或分布外移动场景？
  • 在规模化计算机使用或桌面基准中，增益有多少来自学习到的策略，多少来自技能库、任务合成或采样策略等周边系统？
  • 观察控制行为能否在短视频平台之外被学习和评测，以减少过度观察与观察不足？
  • 不确定性量化如何从单步接地扩展到长时域GUI轨迹以及内部状态不可访问的闭源部署？
  • 当局限性字段缺失时，需要哪些最低限度的消融和可复现证据来隔离方法贡献？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

61 方法质量 99 近期性 38 可复现性 46 主题相关性

文献综述归纳

研究路线

细粒度与动态任务评测

定义超出点击式成功率的 GUI 任务组合，包括桌面 GUI+CLI 任务、拖拽交互、动态短视频界面，以及多检查点或成本准确性评分。

尚未覆盖：这些评测抽象是否能预测真实任务成功并在非代表性平台和动态内容上迁移，仍不明确。
可扩展监督与在线强化学习

通过可验证任务合成、未标注截图弱监督和面向学习前沿的采样分配，降低对人工标注和低效训练的依赖。

尚未覆盖：在 OSWorld/ScienceBoard 或少量标注校准集之外的泛化证据有限，局限性与可复现细节常未报告。
长时域技能与上下文管理

通过主动上下文动作或多模态技能检索，而不是被动累积历史，改善多步骤代理行为。

尚未覆盖：这些收益能否跨框架、跨应用和跨部署域保持，仍未解决。
可靠性与不确定性框架

评估 GUI 基础能力的后验不确定性和空间校准，以把置信度质量与任务成功率分开衡量。

尚未覆盖：单步基础证据未覆盖多步轨迹；跨模型和跨接口的不确定性迁移在分布偏移下较弱。

研究共性

  • 近来的工作一致从端到端成功率转向同时关注子目标完成、交互覆盖、成本或效率及校准质量。
  • 当前 GUI 代理在观察控制、长时域上下文处理和细粒度交互类型上存在明显能力缺口。
  • 合成、弱监督或检索式外部知识被视为减少对人工标注依赖的重要提升途径。
  • 多篇证据暴露验证或可复现缺口：局限字段为空、工件信号稀缺或跨设置迁移较弱。

关键差异

  • 评测目标：成功导向结果与细粒度子目标/多检查点指标、不确定性或校准质量、成本准确性取舍。
  • 交互跨度：单步可执行基础、多步长时域轨迹和行动前技能检索对代理必须控制的内容有不同假设。
  • 监督与训练路线：可验证合成在线强化任务、未标注截图弱监督、带上下文管理标注的监督微调和冻结的外部技能库。
  • 部署范围：静态桌面与移动端、动态短视频界面、拖拽交互覆盖和 GUI+CLI 混合环境带来不同的观察与动作空间假设。

开放问题

  • 哪些细粒度评测信号最能预测部署成功和跨未见界面迁移？
  • 如何在单一动态平台之外设计和衡量观察控制？
  • 在何种条件下不确定性排名与校准能从开源单步基础迁移到闭源多步代理？
  • 那些可复现证据稀疏或未报告失败模式的方法隐藏了哪些局限？
  • 技能与上下文管理方法跨应用、框架和部署域的泛化程度如何？

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

58 方法质量 99 近期性 38 可复现性 44 主题相关性

文献综述归纳

研究路线

面向推理框架的智能体训练与编排系统

对嵌入复杂推理框架或实时浏览器环境的智能体进行端到端强化学习或在线策略优化，并提供可扩展回滚隔离与轨迹收集。

尚未覆盖：训练后错误恢复仍弱；框架设计影响可训练性；可见复现工件与独立部署证据有限。
弱监督与扩散式GUI策略模型

以有限标注或替代解码方式训练视觉定位与导航策略，覆盖移动、桌面和网页控制。

尚未覆盖：跨平台泛化、与更大或专有系统的对比广度，以及未报告的限制仍不明确。
计算机使用智能体的可复用技能与记忆层

将已验证GUI轨迹或文档化流程转化为多模态或可调用工件，以降低token成本、执行时间和重复规划。

尚未覆盖：确定性回放仅在前提条件匹配时有效；模糊、不兼容、动态或异步界面步骤尚未充分评估。
GUI智能体的步骤级诊断与安全基准

在浏览器或编码设定中隔离状态转换理解与对抗安全，覆盖时序排序、动作推断和提示注入。

尚未覆盖：离线、特定操作系统和预设动作词汇限制生态效度；优化攻击复现及更广攻击面未被直接测量。

研究共性

  • 2026年前沿将GUI智能体视为可运行系统，而不是静态模型，闭环执行、任务成功率与成本/延迟成为主要评估信号。
  • 普遍尝试通过未标注截图、实时交互或已验证轨迹来减少昂贵标注与重复规划。
  • 评估从最终任务完成扩展到步骤级状态转换、失败诊断和对抗安全行为。
  • 系统借助代理、编排器或容器化执行将策略学习与复杂的框架/浏览器基础设施解耦。

关键差异

  • 学习信号不同：未标注截图的弱监督加小量校准、真实环境在线多轮强化学习、扩散解码的监督微调，或无策略训练的检索/回放。
  • 工件与表示不同：视觉增强技能库保留界面图像，可调用记忆编码前提条件和动作载荷，模型中心方法把行为写入权重。
  • 评测深度不同：有的关注端到端基准成功率，有的关注步骤级时序排序与动作识别，有的关注提示注入下的对抗任务完成。
  • 部署设定不同：离线诊断无法捕捉异步实时动态，而实时浏览器和容器化执行带来不同的复现与安全边界。

开放问题

  • 训练后强化学习能否稳定提升错误恢复，框架设计对可训练性的限制有多大？
  • 技能与记忆系统能否在模糊、异步或跨操作系统交互中超越确定性回放边界？
  • 安全加固能否跨应用领域迁移，还是本质上取决于任务表面和优化攻击形式？
  • 在多篇论文缺乏可见代码、数据集或工件链接的情况下，独立复现能提供什么证据？

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

63 方法质量 99 近期性 37 可复现性 49 主题相关性

文献综述归纳

研究路线

真实桌面与操作系统任务评测

跨应用捕获异构GUI与CLI工作流，并通过确定性、细粒度子目标评分替代仅最终成功。

尚未覆盖：覆盖范围限于特定桌面、移动或短视频场景，向未见应用和真实用户工作负载迁移尚未建立。
多模态技能与重放记忆构建

复用已验证轨迹或视觉文档，提升重复计算机使用任务的成功率并降低token/时延成本。

尚未覆盖：UI漂移下的维护、模糊前提条件与跨应用泛化尚未充分验证。
动态、视频引导与拖拽交互定位

将代理从静态点击式GUI动作扩展到短视频动态界面、关键帧引导任务和拖拽操作。

尚未覆盖：观察控制以及在动态界面类型上的泛化仍缺失，尤其超出所研究的短视频/拖拽领域。
专用视觉语言GUI代理架构

通过预训练或微调多模态模型实现GUI定位与导航，并探索块级扩散等替代解码方式。

尚未覆盖：对比证据限于选定的定位/导航基准；鲁棒性、交互可靠性与部署权衡仍报告不足。

研究共性

  • 需要超越最终成功的细粒度评测；子目标完成、成本准确率、token/时延效率能揭示Pass@1掩盖的差异。
  • 可复用的多模态技能或重放记忆相比无记忆或纯文本基线提升代理表现与效率。
  • 当前GUI代理在动态、拖拽式或GUI/CLI混合任务上仍未达到人类水平，观察控制与UI定位是薄弱点。
  • 确定性、基于规则或经工件验证的检查有助于可复现的基准评测。

关键差异

  • 任务焦点差异显著：静态桌面工作流与连续动态屏幕/短视频动态不同，隐含不同的状态表示与观察需求。
  • 复用机制不同：带视觉图形的分层多模态技能库、编译状态机重放、参数可控的可调用记忆各有侧重。
  • 改进策略不同：有的改变数据或微调，有的改变运行时记忆/框架，还有的改变生成模型架构。
  • 评测目标不同：通过任务、最小化成本/时间、提升定位/导航得分未被视为统一目标。

开放问题

  • 所研究基准上的提升能否迁移到基准应用和平台之外的真实办公、移动或专业工作流？
  • 应用UI、工作流或用户目标变化时，技能与重放记忆应如何失效或修复？
  • 如何显式建模并评测观察控制，而不只限于短视频成本准确率场景？
  • 拖拽式与视频引导定位方法与记忆、技能或扩散型代理骨干结合时，跨基准泛化如何？
  • 部分方法缺少代码、数据集与局限性细节；哪些报告改进能在独立部署中复现？

survey

Surveys, taxonomies, tutorials, position papers, or roadmap papers for GUI agents

56 方法质量 99 近期性 37 可复现性 43 主题相关性

文献综述归纳

研究路线

分类体系与路线图综合

把碎片化的GUI智能体方向整理为研究缺口和优先路径。

尚未覆盖：综合是否由系统证据支撑，而非选择性的方法或基准示例。
对比评测与基准设计

为网页、移动和视频引导GUI智能体建立受控任务和可比较的量化指标。

尚未覆盖：跨设置结果兼容性、多步轨迹覆盖，以及目标特定的重新校准。
可验证任务合成与强化学习

通过可验证任务和在线强化学习扩展训练信号与rollout效率。

尚未覆盖：基准到真实部署的偏差，以及对验证器或奖励校准的依赖。
GUI grounding与不确定性估计

量化GUI grounding可靠性，并构建共形点击区域等空间安全机制。

尚未覆盖：跨模型层级与接口的迁移，以及分布偏移下的校准。

研究共性

  • 进展大多以基准-方法配对贡献呈现，并使用定量成功率、排序或安全指标。
  • 自主或可验证评估信号被广泛采用，但通常被视为有噪声，需要校正或领域特定再验证。
  • 泛化声明依赖分布外设置上的迁移，但证据显示迁移是选择性的，而非统一的。

关键差异

  • 评测目标不同：单步grounding和视频引导任务，与多步桌面、移动、欺诈检测和安全红队轮次不同。
