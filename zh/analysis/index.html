GUI/web/mobile/OS automation datasets, environments, tasks, metrics, and benchmarks

文献综述归纳

研究路线

真实桌面/OS任务基准

构造多应用计算机使用任务，覆盖GUI与CLI工作流，采用确定性评分并进行跨框架/模型基线比较。

尚未覆盖：对OS与应用状态覆盖仍有限；细粒度子目标得分未必对应终端用户任务成功或部署效用。
专门交互与动态屏幕基准

填补点击式静态任务之外的空白，覆盖动态短视频平台、拖拽交互与视频引导GUI任务。

尚未覆盖：各基准仍限于特定平台或交互类型；代理仍表现出观察控制较弱，尚未达到人类级成本准确性。
指标与不确定性/压力测试设计

通过细粒度多检查点评分、成本准确性权衡和后验不确定性量化来探测可靠性。

尚未覆盖：UQ排名跨模型层级和接口迁移较弱；分布或接口不匹配下共形覆盖下降；代理指标未必对齐部署效用。
可扩展任务/数据工件与训练导向评测

生成可验证训练任务、弱监督定位数据、多模态技能库和大规模拖拽数据集，以改进并评测代理。

尚未覆盖：训练/测试分离、跨应用复用以及性能向未见基准的迁移在证据包中仍缺乏充分验证。

研究共性

  • 当前工作将GUI自动化视为交互式多步环境评测，而非静态视觉问答。
  • 在总体成功率之外，越来越多引入过程、成本或不确定性信号。
  • 前沿模型在稳健观察控制和未充分覆盖的交互类型（如动态内容、拖拽）上仍存在明显失败。
  • 评测通常跨多个VLM或代理框架进行比较，但结论常受限于特定平台或数据集。

关键差异

  • 评测目标从单步GUI定位、完整桌面工作流到动态或视频引导交互不等，强调不同失败模式。
  • 交互覆盖不同：点击/输入、GUI加CLI、拖拽和短视频滚动；有的隔离动作定位，有的评估工作流完成。
  • 监督与数据来源不同：弱监督截图、可验证合成任务、技能库和人工设计任务集。
  • 评分约定不同：Pass@1、子目标完成、成本准确性、排名相关性、共形覆盖与技能提升不可直接互换。

开放问题

  • 细粒度子目标和成本感知指标是否与真实用户效用或部署中的任务完成一致？
  • 不确定性排名与校准能否跨模型家族和接口设置迁移，而无需目标特定重排名？
  • 基准如何覆盖动态、拖拽和视频引导交互，同时避免过度平台特定化？
  • 合成或弱监督训练数据集在复用为评测集时是否会产生泄漏或过拟合？
  • 在工件可见性不均的情况下，基准结论跨框架、算力和重实现是否稳定？

method

GUI agent models, planning, grounding, action prediction, training, or reasoning methods

60 方法质量 99 近期性 39 可复现性 46 主题相关性

文献综述归纳

研究路线

GUI 定位与动作表示方法

学习将屏幕或视频观察映射为点击、拖拽和上下文管理等动作；包括任务驱动的关键帧提取和从未标注截图学习视觉定位。

尚未覆盖：所学报表示能否迁移到报告界面族之外，以及拖拽或上下文即动作等动作空间是否足以处理未见长时程任务。
训练数据与目标设计方法

通过弱监督视觉定位、可验证任务合成、带前沿采样的在线强化学习和紧凑上下文表示，降低标注成本并提高样本效率。

尚未覆盖：数据配方、任务生成器、强化学习目标和基础 VLM 的相对贡献尚未隔离；所报基准之外的数据质量和多样性仍未验证。
规划、观测控制与长时程上下文管理

将感知连接到动态和长时程界面中的干预，把观察或记忆更新视为第一类动作，并用动作准确率与信息成本联合评分。

尚未覆盖：收益是否来自策略的规划/上下文管理而非定位模型，以及观测控制行为能否跨平台迁移。
评估、不确定性与消融协议方法

通过确定性评分、细粒度子目标指标和 GUI 定位的后验不确定性量化，区分模型能力与框架、任务效应。

尚未覆盖：不确定性排名跨模型类别迁移弱，且主要在单步定位中验证；多篇论文未见代码、数据集或局限性证据，消融强度部分未核验。

研究共性

  • Pass@1 单独不够；细粒度子目标、成本-准确率或校准指标能揭示成功分数相似代理之间的差异。
  • 屏幕定位与动作定位仍是静态、动态、拖拽和长时程 GUI 任务中的核心瓶颈。
  • 评测正从静态离线截图转向真实或浏览器保真的交互式环境。
  • 数据效率受到重视：弱监督、可验证任务合成、在线强化学习和上下文压缩都被用来降低标注成本并提升训练效率。
  • 动态和长时程环境提出了动作成功之外的新需求，尤其是观测控制、记忆管理和不确定性感知。

关键差异

  • 评测目标不同：macOS 桌面 GUI 与 CLI 混合任务、移动端长时程任务、动态短视频流、拖拽交互和视频引导任务各自设定不同成功条件。
  • 动作空间不同：方法分别强调单步点击定位、拖拽操作、GUI 与 CLI 操作，或与 UI 动作同时输出的上下文管理动作。
  • 监督信号不同：有的利用大规模未标注截图加少量标注校准，有的为在线强化学习合成可验证任务，还有的使用人工整理的轨迹标注。
  • 模型接口假设不同：不确定性研究依赖开源模型内部状态，同时也测试只能获得动作或输出的闭源模型，难以使用单一一致方法。
  • 贡献归属不同：一个基准将最佳表现归因于技能库而非框架设计，方法论文则归因于训练配方或上下文策略；背后的提升来源未被一致隔离。

开放问题

  • 如何为多步 GUI 轨迹和仅输出动作的闭源代理可靠估计不确定性或校准？
  • 在线强化学习与弱监督中的提升究竟来自任务生成、采样策略、视觉上下文分割、策略目标还是基础模型能力？
  • 观测控制能否作为第一类动作被学习，并从短视频平台泛化到其他动态界面？
  • macOS、移动端、拖拽和视频引导基准能否预测跨应用与跨界面的实际部署表现？
  • 当前若干报告中缺失的代码、数据集、基线和局限性说明背后隐藏了哪些验证缺口？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

62 方法质量 99 近期性 39 可复现性 48 主题相关性

文献综述归纳

研究路线

真实 GUI 任务与交互基准

定义静态多应用桌面、动态短视频和拖拽交互的任务套件与评测指标。

尚未覆盖：测试平台之外的覆盖，以及细粒度指标是否对应部署中的故障降低。
数据高效与可验证训练管线

通过未标注截图、可验证合成任务或在线强化学习减少对人工标注的依赖。

尚未覆盖：跨平台迁移，以及训练收益是否在 OSWorld/ScienceBoard 之外的场景保持可靠性。
结构化技能与上下文组织

压缩长时程历史或可复用多模态流程，以提升多步代理表现。

尚未覆盖：上下文/技能选择如何影响失败模式，以及视觉工件能否跨界面迁移。
定位的不确定性与可靠性框架

为 GUI 定位预测测量后验置信度并构造校准空间区域。

尚未覆盖：多步轨迹不确定性，以及跨模型层级/界面的迁移证据较弱。

研究共性

  • 真实 GUI 评测正从单步受控任务转向多应用、长时程和动态界面。
  • 子目标完成、成本-准确性和校准不确定性等细粒度指标被认为比仅看成败更有信息量。
  • 技能、上下文字段、可验证任务和不确定性区域等结构化工件在评测中优于被动或纯文本基线。
  • 训练方法越来越多采用弱监督、合成可验证任务或在线强化学习以降低标注成本。

关键差异

  • 交互假设不同：动态短视频界面、纯拖拽、GUI+CLI 混合流程和长时程移动任务对观察与动作模型有不同要求。
  • 监督与优化不同：未标注截图预训练加小规模 RL 校准、可验证合成任务在线 RL、以及精选轨迹监督微调。
  • 可靠性重点不同：单步后验不确定性校准、多步观察控制、以及主动上下文管理。
  • 评测范围不同：桌面 OS、短视频平台到移动环境，指标和人类基线各异。

开放问题

  • 单步定位中较强的模型内 UQ 排名迁移是否适用于多步轨迹和界面变化？
  • 可验证合成强化学习任务能否跨操作系统、应用和动态内容泛化，还是收益主要来自基准特化？
  • 如何形式化动态屏幕原生代理的观察控制，以避免过度观察和观察不足？
  • 细粒度基准提升是否能预测 GUI 代理在真实部署中更安全/更可靠？
  • 多篇高排名论文的 limitations 字段为空，负面结果和边界条件可能未被报告，属于验证缺口。

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

59 方法质量 99 近期性 39 可复现性 46 主题相关性

文献综述归纳

研究路线

动作接地的视觉记忆与多模态技能脚手架（用于GUI代理）

通过保留任务相关的局部图像裁剪或多模态技能工件，而非完整截图或纯文本指令，降低UI接地和状态验证错误。

尚未覆盖：这些脚手架是否跨操作系统和预定义动作类型泛化，以及如何避免视觉记忆过载加剧动作级错误。
弱监督视觉接地与数据高效GUI代理训练

通过从大规模未标注截图学习视觉接地，再用少量高质量数据校准，降低人工标注负担。

尚未覆盖：从静态截图和网页到实时异步GUI动态以及更广泛动作空间的泛化尚未被证明。
端到端强化学习与harness原生训练框架

通过记录模型调用或rollout数据，在复杂推理harness或在线浏览器/桌面环境中训练代理。

尚未覆盖：RL后的错误恢复仍弱；harness设计显著影响可训练性，在线rollout多样性和基础设施成本仍未解决。
原生仅截图计算机操作代理与大规模部署脚手架

仅依赖截图输入并输出键盘鼠标动作，无需DOM或可访问性元数据，结合历史压缩和可验证rollout训练。

尚未覆盖：跨平台泛化、长程可靠性，以及超出已报告基准的自适应攻击下的安全性仍开放。

研究共性

  • 视觉接地和任务相关的视觉上下文可以改善GUI状态识别与工作流验证。
  • 在结合监督初始化或弱监督时，轨迹预算适度的开放训练框架可以达到有竞争力的GUI代理表现。
  • 仅看端到端任务成功会掩盖重要失败模式；步骤级迁移、错误恢复和对抗鲁棒性需要单独评估。
  • 脚手架与记忆设计是核心变量：历史压缩、技能检索和局部裁剪会同时影响准确率与失败分布。

关键差异

  • 输入表示不同：纯截图像素、多模态视觉工件、动作接地局部裁剪之间的接地效果与动作级错误权衡不同。
  • 监督信号不同：未标注数据弱监督、在线多轮RL、harness记录RL和大规模可验证rollout训练各有侧重。
  • 评估目标不同：离线步骤级迁移诊断、在线端到端任务成功和对抗安全审计对有效性的假设不同。
  • 部署方式不同：原生键鼠交互、harness或工具编排、浏览器/桌面专用脚手架对运行时控制和状态可观测性的假设不同。
  • 安全证据存在分歧：手工注入模板是否具有代表性尚无共识；浏览器加固的模型在编码域技能注入中仍可能失败。

开放问题

  • 视觉记忆和技能脚手架如何同时降低状态级与动作级错误，并跨操作系统和应用泛化？
  • 何种训练方法能在不依赖特定harness设计的情况下改善RL后的错误恢复？
  • 领域条件安全硬化能否从浏览器任务扩展到编码与桌面操作场景，包括RL优化的注入字符串？
  • 离线迁移诊断指标在多大程度上能预测在线异步部署可靠性？
  • 弱监督视觉接地如何从静态截图和网页扩展到多样交互应用，同时保持低标注成本？
  • 当代码、rollout基础设施或优化攻击字符串未发布时，这些框架和基准的可复现条件是什么？

application

研究路线

跨应用桌面任务基准测试

度量真实桌面工作流中跨应用、含 GUI 与 CLI 混合操作的任务成功率与子目标完成。

尚未覆盖：聚合指标可能掩盖子目标差异；可见证据主要来自 macOS，局限性字段缺失。
应用特定多模态技能检索

为代理提供分层视觉与文本技能文档，改善 UI 元素识别与工作流状态验证。

尚未覆盖：仅在两个基准上评估；跨未见过应用和长任务迁移未证明，局限性字段缺失。
动态屏幕与视频引导任务评测

衡量动态变化界面和视频引导 GUI 任务上的表现，并结合任务感知关键帧选择。

尚未覆盖：动态覆盖限于短视频平台；当前代理缺乏观察控制；视频引导任务泛化未验证。
拖拽式交互定位

构建大规模拖拽交互数据，突破以点击为中心的任务假设。

尚未覆盖：保留集与微调增益可见，但数据/代码释放信号弱；四类拖拽之外的泛化不清。

研究共性

  • 当前研究通过具体基准套件将 GUI 应用任务操作化，采用成功率、子目标或成本-准确率等指标评测。
  • 应用特定先验知识，如可检索技能或已编译的历史运行，能够在准确率或效率上改善代理表现。
  • 视觉基础与状态/历史检查是减少执行错误的常见机制。
  • 单一聚合分数不够；细粒度指标揭示子目标完成、观察效率或良性召回等差异。
  • 方法论与可复现证据不均衡：若干研究未列出局限性，代码/数据/工件释放信息不完整。

关键差异

  • 静态桌面/网页/移动操作与动态屏幕和视频引导观察之间存在差异。
  • 知识表示不同：多模态视觉-文本技能、从轨迹编译的文本状态程序、以及历史摘要与视觉校验。
  • 评测目标不同：跨应用任务成功、信息效率、以及安全导向的良性/欺诈召回。
  • 交互范围不同：仅 GUI 点击/拖拽任务与 GUI+CLI 混合工作流。
  • 部署假设不同：声誉线索被抑制或可用；重复任务记忆与单次运行操作。

开放问题

  • 动态界面中的过度/不足观察能否通过显式观察控制策略改善而不损失任务准确率？
  • 多模态技能库与编译重放程序能否跨未见过应用、平台或更长工作流泛化？
  • 基准收益在实际自动化和安全敏感网页任务中如何映射为可靠性结果？
  • 在声誉捷径不可用时，反欺诈代理如何改善良性召回？
  • 在可见证据中，哪些代码、数据、基准工件和局限性文档实际可用，仍需验证。

研究共性

  • 进展主要通过专用GUI/计算机使用环境下的任务成功率或基准分数衡量。
  • 人工奖励和标签正被自动、可验证或模型派生的信号所替代，以扩展训练与评测。
  • 可靠性问题与原始能力并重，涵盖不确定性、安全、泛化和奖励质量。
  • 方法与基准结果针对特定设置，跨论文结论需注意协议、模型访问和评测粒度。

关键差异

  • 评测对象不同：单步可执行grounding与多步移动/浏览器轨迹并存。
  • 模型访问不同：开源权重可观测隐藏状态或logits，闭源模型只能进行行为比较。
  • 成功信号不同：终端二元成功、基准分数、排名迁移、共形覆盖、安全攻击成功率或人类任务完成时间。
  • 训练方式不同：无训练后验基准、监督微调与在线强化学习并用。
  • 稳健性关注点不同：有的屏蔽URL/信誉捷径测欺诈，有的审计提示注入或编码域安全。

开放问题

  • 可用证据包主要包含2026一手方法/基准论文时，GUI智能体综述的实际证据基础是什么？
  • 不确定性量化与排名结果在模型族、接口和分布偏移之间能迁移到什么程度？
  • 单步grounding结果能否预测多步任务完成、安全性和长时上下文管理？
  • 奖励噪声、良性召回、域条件安全、上下文泛化与证据覆盖缺口中，哪些最需要优先解决？
  • 自动任务或评估器信号在扩大规模时，是否会让结论偏向易验证或已被充分覆盖的设置？
