benchmark

GUI/web/mobile/OS automation datasets, environments, tasks, metrics, and benchmarks

61 方法质量 99 近期性 39 可复现性 43 主题相关性

文献综述归纳

研究路线

真实桌面与跨应用任务套件

通过规则化多检查点评分，让 GUI+CLI 计算机使用能力在应用和框架之间可比。

尚未覆盖：跨 OS 版本、硬件和工作流的覆盖；确定性评分可能遗漏语义成功或用户偏好。
动态与视频引导界面基准

评估内容在动作间变化以及视频引导交互任务中的代理表现。

尚未覆盖：目前限于短视频/浏览器或选定视频设置；对其他动态界面和长程任务的泛化未充分检验。
细粒度定位、成本效率与不确定性评估

在最终任务准确率之外，考察 UI 定位、观察效率和置信度校准。

尚未覆盖：单步不确定性证据未覆盖多步代理轨迹；跨模型、跨接口的排名迁移较弱。
基准驱动的自改进与训练方法

利用 OSWorld/ScienceBoard/CUA-World 等套件，通过 harness 编辑、RL、弱监督或可验证任务合成改进冻结或开源代理。

尚未覆盖：任务合成和 harness 优化可能过拟合基准表面；跨套件迁移和真实部署证据不足。

研究共性

  • 可执行环境的保真度很重要：研究趋向真实桌面/浏览器设置，而非仅静态截图。
  • 总分不够：多检查点、成本-准确率、子目标和不确定性/校准等细粒度指标能揭示 Pass@1 隐藏的差异。
  • 前沿 GUI 代理仍存在可观察的能力缺口，尤其是观察控制、定位迁移和跨界面泛化。
  • 对同一冻结骨干，训练/harness/技能干预可提升表现，说明评测结论对执行框架和环境敏感。

关键差异

  • 评测目标不同：单步 GUI 定位、多步桌面工作流与动态/视频引导屏幕各有侧重。
  • 干预方式不同：检索多模态技能、优化执行 harness、弱监督或在线 RL 训练、可验证任务合成。
  • 指标重点不同：确定性规则评分、成本-准确率效率、不确定性排名迁移与 SOTA 成功率。
  • 部署设置不同：真实 macOS 桌面、浏览器模拟平台、视频引导任务或容器化 OSWorld/ScienceBoard 任务。

开放问题

  • 当前任务分布是否覆盖计算机使用代理预期帮助的真实设置，例如长程工作流、OS/版本漂移和权限受限应用？
  • 当 Pass@1、成本-准确率和不确定性排名不能跨模型或接口迁移时，哪些细粒度指标最能预测下游用户效用和部署安全？
  • 在 harness 优化能带来大额冻结模型增益的情况下，基准结论在不同实现、算力预算和重复运行下是否稳定？
  • 不确定性量化能否从单步定位扩展到多步 GUI 轨迹和动态屏幕，而不必针对目标重新排序？
  • 缺失工件和基线细节在多大程度上限制直接比较？报告规范应如何分离方法证据与热度/新近度信号？

method

GUI agent models, planning, grounding, action prediction, training, or reasoning methods

60 方法质量 100 近期性 39 可复现性 42 主题相关性

文献综述归纳

研究路线

GUI能力基准与评估设计

捕捉总体成功率遗漏的子目标进展、信息效率、交互类型覆盖和定位可靠性差异。

尚未覆盖：仅覆盖特定平台或交互类型；部分证据缺少局限性说明；多步可靠性仍未充分检验。
数据高效训练与自改进方法

通过未标注截图、可验证合成任务或围绕冻结模型的harness证据，减少对密集人工标注和重新训练的依赖。

尚未覆盖：跨基准泛化未证实；收益可能依赖harness或数据质量；方法与周边系统的贡献未完全隔离。
动态或非点击接口的观察与动作定位方法

处理界面动态变化、视频关键帧选取和拖拽类动作，扩展纯点击定位。

尚未覆盖：观察控制失败仍未解决；证据限于短视频与部分拖拽类别；更广泛动态界面未验证。
定位的不确定性与可靠性估计

对后验不确定性进行排名与校准，并构造空间共形点击区域以支持安全操作。

尚未覆盖：跨模型层级和接口的UQ排名迁移较弱；仅覆盖单步定位；分布变化下覆盖度下降，训练期方法未涉及。

研究共性

  • 细粒度评估揭示总体成功率掩盖的差异，包括子目标进展、信息成本和动作类型能力。
  • 研究共同关注降低人工标注与再训练成本：利用未标注截图、可验证合成任务、重复运行证据或冻结harness改进。
  • 动态界面与非点击操作仍是薄弱环节，证据显示观察控制、拖拽覆盖和不确定性迁移均有缺口。

关键差异

  • 干预点不同：模型参数训练或微调与冻结模型harness进化、关键帧选择、后验不确定性校准。
  • 评估目标不同：桌面目标完成、动态成本-准确性、视频引导任务、拖拽操作或单步定位可靠性定义不同能力。
  • 监督与验证来源不同：未标注截图加少量标注、多智能体合成可验证任务、重复运行证据与后验UQ分别采纳不同信号。
  • 泛化方式不同：一些研究强调跨平台迁移，另一些固定在单平台或单动作族内，导致测试风险不同。

开放问题

  • 何种观察控制机制能抑制动态界面中的过度观察与观察不足？
  • harness、训练效率和不确定性方法在模型层级、操作系统、应用与交互模式间的迁移边界在哪里？
  • 评估指标如何隔离模型能力与技能库、harness代码和输入预处理的影响？
  • 不确定性校准如何从单步定位扩展到完整多步智能体轨迹？
  • 如何用统一协议覆盖动态视频、拖拽和GUI+CLI等尚未充分测试的界面边界？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

60 方法质量 100 近期性 39 可复现性 43 主题相关性

文献综述归纳

研究路线

任务抽象与交互分类（例如 MacAgentBench、DragOn、LivingScreen）

将GUI智能体能力转化为桌面、拖拽式和动态短视频界面中可测量、可执行或基于规则检查的任务套件。

尚未覆盖：Pass@1可能掩盖子目标差距；平台特定结论和空白的局限性字段使跨领域有效性仍不确定。
外部技能与执行框架改进（例如 VISUALSKILL、GUI-HARVEST）

通过添加多模态视觉技能或依据动作与截图证据演化执行框架，提升冻结骨干智能体的能力。

尚未覆盖：技能工件似乎面向特定应用；跨基准迁移证据主要集中在执行框架优化，且多篇局限性记录缺失。
可扩展监督与可验证强化学习（例如 ScaleCUA、GUICrafter）

通过未标注视觉定位或合成的可验证任务与前沿采样，降低标注成本并支持在线RL。

尚未覆盖：验证环境未必覆盖真实GUI变化；报告提升主要针对特定基准，局限性证据稀疏。
不确定性量化与可靠性框架（例如 Argus）

对GUI定位的后验不确定性信号进行基准测试，测量排序稳定性与共形点击区域校准。

尚未覆盖：证据仅限于单步定位；跨模型与跨接口的排序迁移较弱，分布偏移下覆盖度下降。

研究共性

  • 可执行或基于规则的验证是将GUI任务成功转化为可测量信号的主导方式。
  • 单一Pass@1式成功会掩盖能力差异，需要更细的子目标、成本效率或不确定性指标。
  • 在不过度重训骨干模型的情况下通过外部技能、执行框架或弱监督来提升智能体是共同前沿方向。
  • 训练与评估数据的规模和可验证性被视为GUI智能体能力的核心杠杆。

关键差异

  • 表示方式：静态截图/点击/拖拽抽象与需要观察控制的动态屏幕界面并存。
  • 监督与适应路线：部分方法通过弱监督或在线RL更新策略，另一些保持模型冻结并修改技能或执行框架。
  • 评测目标：成功率、子目标完成度、信息效率和不确定性校准被不同工作分别优化。
  • 部署场景：macOS桌面、短视频平台、拖拽交互和单步定位导致不同的界面稳定性假设。

开放问题

  • 当前任务抽象能否迁移到其原始平台之外的长期、跨应用工作流？
  • 哪些不确定性信号在模型层级和接口之间保持稳定，校准能否承受分布偏移？
  • 可验证RL任务合成能否保持足够的真实多样性，避免对docker或基准环境过拟合？
  • 什么证据能将细粒度子目标指标与下游可靠性、安全性和用户实际任务完成联系起来？

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

59 方法质量 99 近期性 39 可复现性 43 主题相关性

文献综述归纳

研究路线

端到端训练的GUI/计算机使用策略

训练多模态策略对屏幕进行视觉定位并生成动作，减少人工标注或提升桌面、移动、网页基准上的任务成功率。

尚未覆盖：RL后错误恢复仍然弱；跨平台迁移与已报告基准之外的可扩展性缺乏独立验证；许多摘要未明确说明局限。
Harness原生RL与编排框架

通过拦截模型调用并在隔离环境中运行有状态多进程推理，把已部署的智能体harness转化为可训练的rollout。

尚未覆盖：Harness设计显著影响可训练性；恢复等能力仍然较弱；代码、数据集等可复现信号不完整。
GUI智能体的技能与记忆层

把已验证轨迹或编写文档转化为可复用多模态技能或可重放记忆，以降低token成本、执行时间和定位错误。

尚未覆盖：记忆复用受确定性或兼容运行态限制；技能构建按应用定制，覆盖范围需超出已测应用。
面向恢复与个性化的诊断评测

测量智能体在恢复一致性或用户偏好执行上何时、为何失败，而不只看总体任务完成度。

尚未覆盖：当前智能体在个性化任务上大幅下滑且未利用潜在恢复能力；理想恢复依赖条件模拟，长时程重放成本未解决。

研究共性

  • GUI/计算机使用智能体需要视觉定位，并需要在真实交互任务上进行环境扎根评测。
  • 外部运行层——训练循环、技能库、记忆或评估harness——可以在不重新训练基础模型的情况下提升任务成功率或效率。
  • 报告的性能通常以任务成功基准和匹配基线衡量，但错误恢复、个性化和适应性在各系统中仍然较弱。
  • 可执行、可复现的工件供给仍不均衡；缺失代码、数据集或局限细节属于验证缺口，不应视为该工作没有这些内容的证据。

关键差异

  • 一种路线在统一动作空间上训练端到端策略，另一种保持基础智能体固定并叠加外部技能、记忆或RL代理。
  • 监督来源存在差异：未标注截图的弱监督、应用-工件混合监督，或在已部署harness中进行的在线RL。
  • 评测目标不同：有的关注聚合基准成功率，有的关注恢复一致性和偏好执行等诊断性失败模式。
  • 动作输出空间不同：有的仅输出GUI动作，有的统一输出GUI+代码；生成范式也存在扩散生成与常见LLM解码的差异。

开放问题

  • 后训练或记忆层能否减少错误恢复失败？现有证据显示RL后恢复能力仍然较弱。
  • 技能与可重放记忆系统能否跨出确定性、单应用或基准特定条件进行泛化？
  • 基于未标注截图的弱监督能否扩展到更广泛的计算机使用任务，同时保持已报告的数据效率优势？
  • 如何独立于总体任务成功率评测个性化与恢复，哪些指标最能反映用户特定执行？

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

64 方法质量 99 近期性 39 可复现性 47 主题相关性

文献综述归纳

研究路线

真实GUI基准与交互评测套件

定义桌面、拖拽、动态短视频和视频引导GUI任务及指标，暴露最终成功率之外的失败模式。

尚未覆盖：覆盖通常局限于特定平台或交互类型；动态环境中的成本精度仍未达到人类水平，部分基准缺少代码、数据或局限性说明。
面向电脑使用智能体的技能、记忆与重放复用

通过检索多模态技能或将成功运行编译为带屏幕检查的状态机，提升准确率或重复任务执行速度。

尚未覆盖：跨应用、跨平台和任务变体的迁移，以及屏幕状态不匹配时的鲁棒性尚未建立；视觉、文本和程序化工件缺乏统一比较。
端到端模型训练与统一动作空间

训练多模态智能体生成GUI动作，部分方法统一GUI与代码执行，减少对脆弱工具组合的依赖。

尚未覆盖：除了报告基准之外的真实泛化、跨平台迁移，以及统一训练与模块化工具或技能组合之间的边界仍不清晰。
点击之外的观察与交互接地

用数据集、关键帧或动态浏览器环境表示拖拽、动态内容和视频引导任务，以改善视觉接地和动作覆盖。

尚未覆盖：动态屏幕上的过度观察和观察不足问题未解决；关键帧提取收益主要在VideoQA或agentic基准中展示，缺乏广泛专业应用验证。

研究共性

  • 仅看最终成功率不够，需要通过子目标完成度、成本效率或信息效率等更细粒度指标反映行为差异。
  • 可复用任务工件，如多模态技能、编译后的状态机或关键帧，相比一次性生成能提升准确率或速度。
  • 当前前沿智能体在动态屏幕、拖拽操作和视频引导任务中的观察与交互控制仍然不足。
  • 端到端训练或统一动作空间相对简单工具组合或无技能基线能带来GUI表现提升。

关键差异

  • 在应持久化什么工件上存在分歧：有的保留视觉加文本技能，有的编译为状态机程序，有的提取任务相关关键帧。
  • 适应方式不同：有的通过端到端训练和在线强化学习，有的在推理时检索或重放，监督成本和泛化预期不同。
  • 评测场景不同：真实桌面GUI与CLI、浏览器动态短视频、拖拽交互、视频引导任务以及多平台导航与接地基准各自强调不同约束。
  • 成功标准不同：最终成功率、细粒度检查点、成本精度、延迟加速或相对基准提升，导致直接比较困难。
  • 动作空间设计不同：有的输出GUI点击或坐标，有的统一GUI与代码执行，有的专门处理拖拽或观察控制。

开放问题

  • 技能库和编译后的重放程序在跨应用、跨操作系统和屏幕状态变化时能否稳健迁移，而不依赖脆弱的回退？
  • 智能体能否学习观察控制策略，在动态短视频或实时界面上避免过度观察和观察不足？
  • 视频引导关键帧、拖拽接地和操作系统级基准上的收益是否转化为真实办公和专业工作流中的能力？
  • 当动作空间同时包含GUI操作和代码执行时，端到端训练与模块化检索或重放之间的边界应如何划定？
  • 若干论文缺少明确局限性或代码、数据集信号，因此可复现性和负面结果仍是证据缺口。

survey

Surveys, taxonomies, tutorials, position papers, or roadmap papers for GUI agents

56 方法质量 99 近期性 37 可复现性 41 主题相关性

文献综述归纳

研究路线

受控评测与缺口映射

通过受控基准和审计协议，把GUI智能体声明转化为可测量的失败模式，覆盖定位、安全、欺诈检测、不确定性和可复现性。

尚未覆盖：各基准只隔离狭窄设置；跨界面、跨模型和跨攻击迁移往往较弱，采样证据也未提供跨缺口的系统优先级排序。
密集监督与可验证任务合成

利用受控桌面环境、密集元素标注、大规模合成语料和可验证RL任务生成，缓解计算机使用智能体的数据与任务稀缺问题。

尚未覆盖：从合成或受控环境到未见真实应用和长程可靠性的迁移只得到部分验证；分布偏移和应用状态覆盖仍未解决。
Harness、上下文与策略优化

通过优化执行harness、主动管理长程上下文或高效分配rollouts，在不重新训练完整骨干模型的情况下改进冻结或小模型表现。

尚未覆盖：证据集中于OSWorld、ScienceBoard、移动端等基准；更广泛的跨基准泛化与失败边界仍需独立验证。
视频引导任务定位

通过抽取任务相关关键帧并在视频引导交互任务上评估MLLM智能体，桥接视频理解与GUI动作。

尚未覆盖：关键帧收益在视频问答和GUI任务基准上有体现，但与多步智能体轨迹及更广泛GUI环境的整合尚不明确。

研究共性

  • 研究趋于一致地把GUI智能体评测视为受控环境中的任务完成或失败模式测量。
  • 多项工作通过监督、上下文、harness或rollout变化改进预训练智能体，而非仅扩大模型规模。
  • 安全、不确定性和可复现性正在成为一级评测关注点，而不是辅助检查。
  • 任务成功率、定位精度、攻击成功率和排名稳定性等基准特定指标成为标准，并用留出或迁移测试检验泛化能力。

关键差异

  • 评测目标不同：有些工作测量单步定位或不确定性校准，有些测量长程任务完成、欺诈判断或安全攻击成功率。
  • 监督模式不同：密集环境标注、可验证RL任务合成、重复运行harness编辑和人工攻击模板强调不同失败信号。
  • 交互表面不同：桌面、移动、网页、短信到网页、编码和视频引导任务对应不同观察空间与动作空间。
  • 泛化声明不同：部分论文报告跨基准迁移，另一些则报告跨模型层级或领域迁移较弱，建议针对目标重新验证。
  • 可复现性证据不同：有些论文提供代码、数据集或工件信号，有些只有论文级证据且缺少局限性说明，使验证缺口难以比较。

开放问题

  • 哪些基准特定的改进能迁移到测试桌面、移动、网页、编码、短信和视频引导设置之外的现实GUI工作流？
  • 在缺少系统覆盖证据的情况下，综述和分类工作应如何在定位、长程记忆、安全、不确定性和数据合成之间排序缺口？
  • 不确定性排名或安全加固在什么条件下能跨模型层级和界面领域迁移？
  • 密集合成监督或可验证任务合成能否在分布偏移和未见应用状态变化下保持收益？
  • 当前可见前沿中，缺失的代码、数据集、指标、基线和局限性说明隐藏了哪些可复现性缺口？
