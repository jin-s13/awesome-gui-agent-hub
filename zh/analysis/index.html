GUI/web/mobile/OS automation datasets, environments, tasks, metrics, and benchmarks

文献综述归纳

研究路线

真实与动态 GUI/计算机使用基准构建

为桌面、浏览器和应用自动化建立共享任务，使代理在现实交互约束下完成屏幕定位、动作选择和多步目标。

尚未覆盖：各套件对平台和交互模式的采样仍偏窄；动态内容、拖拽、GUI+CLI、跨应用流程只被部分覆盖。
细粒度指标与不确定性/压力测试设计

超越总体成功率，衡量子目标完成、观察效率、定位确定性和空间安全。

尚未覆盖：代理指标尚未与下游用户决策对齐，不确定性排序在模型类别和界面间迁移较弱。
面向基准评测的训练数据、任务合成与技能库方法

通过弱监督、可验证合成任务或多模态技能检索降低标注依赖并提升代理表现。

尚未覆盖：性能提升究竟是真实能力还是基准特定分布所致，以及能否迁移到未见应用和部署环境仍不清楚。
可比评测协议与多框架基线

提供确定性检查、多模型多框架比较和可审计工件。

尚未覆盖：实现、算力预算和闭源内部状态访问下的稳定性尚未建立；部分成果缺少明确的局限性与工件证据。

研究共性

  • GUI/计算机使用评测需要覆盖静态点击之外的现实环境，近期工作汇集到桌面 OS、动态视频流、拖拽和跨模态流程。
  • 单一通过率不够；细粒度子目标、成本-准确性、校准和观察效率指标能揭示模型差异。
  • 当代理能访问技能、课程或可验证合成任务等结构化工件时，定位和动作选择往往优于仅依赖屏幕像素与文本。
  • 当前代理在观察控制、子目标完成和不确定性感知决策上仍弱于人类，因此基准同时承担压力测试角色。

关键差异

  • 评测目标：有的工作评估单步可执行定位与校准，有的评估多步桌面/网页轨迹或任务级通过率。
  • 交互与部署设置：环境分为真实 macOS 桌面、浏览器短视频模拟、拖拽专项数据集和视频引导 GUI 任务。
  • 监督与学习信号：人工标注、未标注截图弱监督、可验证在线 RL 合成和技能库检索之间存在差异。
  • 成功指标不同：Pass@1、细粒度检查点得分、成本-准确性、UQ 排序迁移和校准空间覆盖可能给出不同排名。

开放问题

  • 当前基准分布是否覆盖真实 GUI 交互的完整空间，包括拖拽、动态内容、CLI+GUI 和跨应用流程？
  • 不确定性与共形覆盖在开源/闭源模型层级、不同界面或部署偏移下是否仍可靠？
  • 可验证任务合成与弱监督学到的是通用计算机使用能力，还是主要拟合特定基准的成功信号？
  • 当总体成功率与子目标得分不一致时，哪些指标最能预测用户侧可靠性和决策效用？

method

GUI agent models, planning, grounding, action prediction, training, or reasoning methods

61 方法质量 99 近期性 39 可复现性 44 主题相关性

文献综述归纳

研究路线

面向计算机使用智能体的任务合成与弱监督训练

减少对昂贵人工标注的依赖，通过未标注截图进行视觉定位，或通过可验证合成任务进行在线 RL，如 GUICrafter 和 SCALECUA。

尚未覆盖：所学策略能否迁移到训练任务族之外，以及改进有多少来自奖励设计、采样效率或基础模型，而不是所提出的目标。
长时域上下文与动作接口管理

通过折叠动作历史、UI 状态和最近步骤记录，在不过载上下文的情况下保留关键事实，使长 GUI 轨迹可处理，如 MemGUI-Agent。

尚未覆盖：能否泛化到其他接口和更长时间范围，以及在缺少精心标注轨迹或移动端之外，上下文即动作是否仍然有效。
动态、视频和拖拽式定位基准

在动态屏幕、视频引导任务和拖拽交互上评估 GUI 智能体，补足点击式基准缺失的覆盖；关键帧提取用于从动态视频观测中选择任务相关帧。

尚未覆盖：对短视频或拖拽任务之外的覆盖不足，关键帧提取是否提升 GUI 动作预测而不只是 VideoQA，以及其他动态界面上的观察控制表现仍不清楚。
细粒度评估与不确定性量化协议

用子目标完成、成本-准确性、动作正确性和校准不确定性替代纯成功率，并测量不确定性排名的选择性迁移和共形点击区域。

尚未覆盖：多数证据仍停留在单步或基准范围内；多步轨迹、跨模型不确定性迁移和分布偏移鲁棒性尚未建立。

研究共性

  • 评估正从端到端任务成功转向更细粒度信号，如子目标完成、成本-准确性、动作正确性和不确定性校准。
  • 可靠的 GUI 智能体需要显式的观察和上下文管理，尤其在屏幕动态变化或历史较长时。
  • 合成、弱监督和可验证训练信号能降低标注成本，但尚未证明能迁移到训练分布之外。
  • 交互覆盖很重要：仅点击式基准会遗漏拖拽、混合 GUI/CLI、视频引导和动态内容工作流。
  • 可复现性和评估工件仍不均衡；部分工作提供数据或代码，部分仅报告聚合结果或未说明局限性。

关键差异

  • 监督信号不同：未标注截图的弱视觉定位，区别于可验证 RL 轨迹、人工监督微调或仅基准探测。
  • 评估目标不同：Pass@1 和子目标评分，区别于成本-准确性、不确定性排名、共形覆盖和拖拽动作正确性。
  • 表示方式不同：静态截图定位，区别于任务驱动关键帧提取和结构化折叠上下文字段。
  • 交互模式不同：点击/键入、拖拽操作、混合 GUI/CLI、短视频动态内容和长时域移动工作流未统一覆盖。
  • 部署场景不同：macOS 桌面、基于浏览器的短视频平台和移动设备具有不同环境假设。
  • 贡献归因不同：报告收益可能受技能库、基础模型、框架或训练数据混淆，证据设计在隔离方法贡献方面不一致。

开放问题

  • MacAgentBench 最佳配置的收益有多少来自技能库，而不是基础模型或框架设计？
  • LivingScreen 观察过度和观察不足问题能否被纠正，并且是否迁移到短视频平台之外？
  • TASKER 关键帧提取是否能像提升 VideoQA 那样提升 GUI 动作预测，并且能否帮助静态或非视频 GUI 任务？
  • GUICrafter 和 SCALECUA 在训练任务族和基准之外能迁移多远？
  • Argus 的不确定性排名和共形点击区域能否泛化到多步 GUI 轨迹和闭源模型接口？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

61 方法质量 100 近期性 39 可复现性 45 主题相关性

文献综述归纳

研究路线

基准驱动的任务形式化

为桌面、动态短视频和拖拽等场景定义可复现GUI任务、细粒度评分与交互覆盖。

尚未覆盖：证据限于特定平台与交互类别；任务形式化尚未与可靠保证或长时程安全结果关联。
动态与细粒度交互的形式化假设

显式抽象动态屏幕原生界面以及点击式基准常忽略的拖拽交互原语。

尚未覆盖：假设仍偏描述性；从这些抽象到观察控制保证或跨平台边界的映射未验证。
GUI策略的训练与数据规模化

通过可验证任务合成、在线RL、采样效率与弱监督视觉定位降低标注依赖并提升成功表现。

尚未覆盖：提升主要依据成功率；失败模式、安全约束和分布转移下的迁移未被直接验证。
不确定性与可靠性校准

量化单步GUI定位的事后置信度，并用共形空间区域提示不可靠预测。

尚未覆盖：排名跨模型类别与接口迁移弱；多步轨迹和训练期或混合不确定性未评估。

研究共性

  • 超越端到端成功的细粒度评估正在成为共识，因为相近的Pass@1可能掩盖不同的子目标、观察或定位行为。
  • 多项工作不再采用被动提示上下文，而是将技能、上下文动作或观察控制变为代理系统的显式组成。
  • 当前可靠性证据仍相对基准：方法以任务得分或排名相关性验证，而非跨场景形式保证。

关键差异

  • 评测目标范围不同：静态多应用桌面任务、动态短视频观察、拖拽交互原语、长时程移动工作流。
  • 监督信号不同：可验证合成任务与在线RL、弱监督截图、监督上下文动作轨迹或事后不确定性校准。
  • 交互模式不同：桌面点击/CLI、动态信息流观察控制、拖拽操作或主动上下文管理动作。
  • 部署与可靠性侧重不同：任务成功与效率、空间不确定性区域或记忆/上下文保持；尚未统一为同一安全框架。

开放问题

  • 细粒度成功、成本准确率或子目标指标能否预测真实部署中的可靠性与安全？
  • 需要哪些形式条件来保证动态变化GUI内容下的观察控制，如何在短视频基准之外验证？
  • 事后UQ排名能否在开源/闭源模型及不同定位数据集间无需目标重排而保持稳定？
  • 技能库与主动上下文收益在不同框架、应用和分布外长任务上是否稳健？

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

59 方法质量 99 近期性 38 可复现性 44 主题相关性

文献综述归纳

研究路线

与框架集成的强化学习训练栈

在部署所用的真实框架和环境中对GUI、网页及计算机使用智能体进行端到端策略改进，包括实时浏览器和容器化rollout。

尚未覆盖：强化学习后的错误恢复仍弱，且部分框架更难训练；跨团队复现和实时基础设施漂移尚缺证据。
弱监督下的数据高效策略获取

利用海量未标注截图进行视觉定位，再以少量高质量数据校准，降低GUI智能体对昂贵人工标注的依赖。

尚未覆盖：证据限于所报告的截图与网页设置，尚未覆盖实时多步异步计算机使用任务和失败恢复。
可复用技能与可回放记忆编排

将验证过的GUI流程缓存为多模态技能或参数可控记忆，以降低重复规划、token成本和执行时间。

尚未覆盖：确定性适用检查会拒绝模糊或不兼容步骤，跨应用、UI变化和长程恢复的可迁移性仍未解决。
替代性多模态生成骨干

将块级扩散生成引入视觉语言GUI智能体，目标覆盖移动、桌面和网页平台的grounding与导航。

尚未覆盖：可见证据缺少局限性分析，实时交互所需的推理延迟、吞吐和部署规模权衡尚不明确。

研究共性

  • 执行导向评测处于核心位置：系统通过任务成功、产物检查或环境状态来判定，而非仅依赖静态预测。
  • 框架与环境设计显著影响智能体能力；训练、记忆和评测越来越与实际部署接口耦合。
  • 即使使用强基础模型，当前计算机使用智能体在状态验证、错误恢复和专业软件使用上仍存在明显差距。
  • 已发布工件完整性不一：多篇论文报告了开源框架或基准环境，但局限性与可复现证据并非普遍完整。

关键差异

  • 监督信号不同：未标注截图的弱监督、在线多轮强化学习、以及检索式技能或记忆执行并存。
  • 系统优化目标不同：端到端任务成功、步骤级转换理解、token/时间开销或领域科学价值。
  • 交互与表示方式不同：含视觉图形和MCP工具的多模态技能文件、参数可控回放轨迹记忆，或扩散式多模态策略。
  • 部署设置不同：容器化多进程框架rollout、实时网页浏览、离线Linux桌面诊断和专家科学软件环境。

开放问题

  • 为什么强化学习后的错误恢复和框架特定可训练性仍然较弱，哪些框架特性可以改善？
  • 未标注截图上的弱监督视觉定位能否可靠迁移到实时多步GUI任务？
  • 确定性回放记忆在精确前置条件不再满足时能扩展到何种程度？
  • 离线GUI转换诊断能否预测实时异步计算机使用环境中的性能？
  • 当前VLM缺失哪些科学软件能力，哪些失败来自框架或评测误差？

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

64 方法质量 99 近期性 37 可复现性 48 主题相关性

文献综述归纳

研究路线

真实 GUI 任务评测：覆盖桌面、动态视频与拖拽交互

捕捉领域任务多样性、细粒度子目标评分、动态内容行为以及非点击交互，弥补单一点击式评测的盲区。

尚未覆盖：跨操作系统、应用版本、平台动态和语言的泛化不明确；若干评测缺少可验证的代码或数据集工件。
技能库与执行记忆方法：复用 GUI 智能体行为

将经验证的轨迹或多模态应用知识编码为可调用技能、状态机程序或记忆，以降低 token/时间成本并提升重复工作流完成率。

尚未覆盖：在 UI 元素、应用状态或任务输入变化时的可靠性与回退机制未充分测试；长期记忆维护和确定性边界仍不清楚。
多模态 GUI 智能体模型训练与架构

训练或微调视觉语言智能体，使其在移动、桌面和网页界面中完成元素定位和导航；扩散式生成提供自回归策略之外的替代路线。

尚未覆盖：grounding/导航指标增益尚未证明可迁移到未见过应用、动态界面和真实部署中的推理成本与安全约束。
视频引导观察与关键帧提取

通过任务相关、场景感知的关键帧选择连接视频理解与 GUI 交互，并用成本感知准确率评估动态内容。

尚未覆盖：在动态内容上没有模型达到人类水平成本-准确率；VideoQA 关键帧提升能否转化为稳定交互式 GUI 任务表现仍未知。

研究共性

  • 当前 GUI 智能体已在真实多应用桌面和动态界面上评测，但细粒度或成本感知指标暴露了聚合成功率掩盖的缺陷。
  • 结构化复用——视觉/文本技能、状态机程序或可调用记忆——能显著提升效率，并相对于逐步语言模型控制有时也能提升任务完成度。
  • 交互广度很关键：拖拽、视频引导和动态变化屏幕内容暴露了主要为点击式静态界面设计的智能体的弱点。
  • 截图、UI 图形或选定关键帧等视觉 grounding 信息有助于元素识别和工作流状态验证。

关键差异

  • 改进路径不同：外部技能/记忆包装、模型架构训练和通过关键帧提取的输入条件化，对增益来源假设不同。
  • 评测目标不同：任务成功率、成本-准确率、grounding/导航、子目标完成和 VideoQA 邻近指标之间难以直接比较。
  • 界面与平台覆盖不同：带 CLI/GUI 的桌面办公应用、动态短视频平台、拖拽交互和移动/网页 grounding 各自被单独关注。
  • 可复现证据不同：部分方法报告强结果，但可见的代码、数据集或工件信号仍缺失或较弱。

开放问题

  • 什么观察控制或记忆验证机制能让 GUI 智能体在持续变化或用户特定界面上同时保持准确与成本高效？
  • 当应用布局、操作系统版本或任务前置条件偏离原执行轨迹时，技能或回放方法能否保持安全有效？
  • 基于拖拽或视频引导交互数据的微调能否迁移到评测套件之外的一般计算机使用任务？
  • 回放式和扩散式方法能否结合，既实现重复任务快速执行，又不牺牲对新工作流的泛化？

研究路线

对比评测与受控基准构建

建立受控协议，在去除信誉捷径或不可观测内部状态等便利线索后，测试 GUI/计算机使用智能体的基础、不确定性校准、欺诈判断与安全性。

尚未覆盖：许多协议只覆盖单步或领域受限任务；跨界面、跨数据集和跨模型开放程度的兼容性尚未建立。
可扩展训练与上下文管理

通过可验证任务合成、在线 RL、噪声奖励校正和结构化上下文压缩，提高智能体在长程任务中的成功率和数据效率。

尚未覆盖：在已评测基准之外的可靠性、奖励噪声传播，以及训练工件的可复现性仍缺乏足够证据。
多模态演示与指导转换

把人类屏幕录制或关键帧转换为教程或压缩后的视觉上下文，以改善人类学习效果和 GUI 智能体规划。

尚未覆盖：生成式指导能否在更广泛 GUI 环境中一致改善智能体能力，目前只得到有限证据支持。

研究共性

  • 当前工作通常把方法贡献与新基准或数据集绑定，以揭示某项智能体能力或具体失败。
  • 评测对象普遍依赖 VLM 智能体在视觉和文本界面状态上执行任务，但协议与结果目标差异较大。
  • 可扩展监督信号是反复出现的主题，包括可验证任务合成、带噪自主奖励、结构化上下文和教程式指导。
  • 性能提升通常与特定基准和模型类别相关，跨设置泛化尚未被充分证明。
  • 安全与不确定性结果随领域、界面和模型访问方式变化，更像是条件性表现而非统一属性。

关键差异

  • 评测目标不同：有的衡量任务成功率，有的衡量不确定性排序迁移、攻击成功率、欺诈判断质量或教程有用性。
  • 监督方式不同：存在基于可验证任务的在线 RL、基于带噪 VLM 判断的 RL、基于标注上下文动作的监督微调，以及不做训练的模型审计。
  • 交互形式不同：视频引导关键帧、移动端长程 UI、浏览器多步攻击、短信到网页欺诈链和屏幕录制教程各自需要不同设定。
  • 模型可观测性不同：开放权重模型可用内部状态，闭源 API 只能依赖外部可观测信号，从而影响不确定性等结论。
  • 安全证据按领域分化：浏览器提示注入抵抗力较强，编码技能注入则可能更容易成功，说明安全性质可能是领域条件的。

开放问题

  • 基准发现能否跨基础、长程、安全与欺诈任务，以及跨开放和闭源模型接口迁移？
  • 当评测噪声和任务规模增加时，哪类奖励信号或任务合成策略对 GUI 智能体仍然可靠？
  • 领域条件安全性是否能从已测试的浏览器与编码场景推广到移动端或视频引导环境？
  • 该主题虽被标记为 survey，但顶部证据多为方法和基准研究；是否缺少针对该领域的系统综述性工作？
  • 部分条目可见复现信号不完整或局限性字段为空；这些应视为验证缺口，而非已有充分边界判断。
