研究路线

真实桌面与OS任务基准

在macOS、Windows等桌面环境中构建跨应用和混合GUI/CLI工作流，比较代理的任务完成与子目标进度。

尚未覆盖：固定任务套件之外的迁移、边界条件覆盖，以及某些基准的局限性证据缺失。
动态与视频引导界面基准

建模操作间内容变化的动态界面和视频引导任务，检验观察效率与关键帧感知。

尚未覆盖：动态界面类型覆盖有限，短视频或视频引导结论外推到其他界面仍缺少证据。
细粒度指标、不确定性与压力测试

在总体成功率之外增加子目标检查点、成本-准确率、定位不确定性和共形点击区域。

尚未覆盖：代理指标与用户决策是否一致，跨模型/接口不确定性排名迁移弱，多步轨迹未被覆盖。
基准驱动的代理改进与可验证训练信号

利用技能、harness优化、可验证任务合成、弱监督和在线RL提升基准性能。

尚未覆盖：提升可能依赖特定基准，部分方法缺少明确局限性或复现边界；实现与算力预算下的稳定性未知。

研究共性

  • 大规模GUI/OS评测需要覆盖真实界面、可验证环境和多个模型/框架，而不能只看静态截图或单步定位。
  • 聚合成功率会掩盖子目标完成、观察成本、置信度校准和技能/harness影响等差异。
  • 当前代理在动态观察控制、GUI定位不确定性、多步工作流等能力上仍明显受限。
  • 评测结论与任务设计、度量选择和可观察接口高度相关。

关键差异

  • 评估目标不同：有工作关注总体成功和检查点，有工作关注成本-准确率，还有工作关注后验不确定性或关键帧效用。
  • 环境设置不同：静态桌面应用、动态短视频界面、视频引导GUI任务和单步可执行定位之间的内容变化和轨迹长度假设不一致。
  • 改进路径不同：有的优化冻结模型的执行框架，有的构建多模态技能，有的做在线RL/任务合成，有的利用未标注截图或关键帧提取。
  • 循证披露不均：部分工作给出局限性，部分为空白，复现信号高低不一；这是验证缺口，不是方法缺点的证明。

开放问题

  • 基准分数在真实桌面/移动/OS部署和界面失调下是否仍成立，尤其跨模型和跨接口的不确定性排名迁移较弱？
  • 细粒度指标、成本-准确率与共形点击区域是否真正对应用户关心的任务完成与安全结果？
  • 观察控制与不确定性校准能否进入多步GUI代理，而不是仅停留在单步定位或短视频任务？
  • 技能库、harness优化、在线RL和弱监督带来的提升是否跨实现、算力预算和基准版本稳定？

研究路线

GUI交互覆盖的基准与评测设计

在粗粒度成功之外提供可测量证据，覆盖桌面GUI加CLI、动态短视频、拖拽操作和视频引导任务，并使用子目标完成、成本准确性等细粒度评分。

尚未覆盖：覆盖仍主要局限于具体平台和任务；动态、拖拽、视频和多步设置在跨环境泛化方面证据不足，缺失的局限性字段使边界推断困难。
面向GUI定位与动作预测的训练和数据效率方法

通过无标注截图的弱监督、可验证合成任务和关键帧提取降低人工标注依赖，并扩展任务覆盖与视频条件下的定位能力。

尚未覆盖：证据未完全隔离数据规模、表示选择或奖励设计对下游模型质量的贡献，跨基准或跨骨干模型的泛化尚未建立。
执行框架与自改进方法

在不更新骨干权重的情况下优化代理周围的可执行框架，利用重复运行和前后截图诊断并修复反复出现的失败模式。

尚未覆盖：收益可能来自执行框架、技能库或任务先验，而非代理推理本身；迁移证据限于少数基准，框架编辑的作用边界需要更多覆盖。
可靠性、观察控制与定位诊断

评估GUI定位是否校准、不确定性排名是否可迁移，以及代理在动态界面上是否控制观察成本，并通过共形点击区域支持空间安全。

尚未覆盖：证据主要为单步定位而非多步轨迹；跨模型和接口的不确定性迁移较弱，分布偏移下覆盖度下降，部署鲁棒性尚未解决。

研究共性

  • 评测正从二元任务成功转向更细的信号，如子目标完成、信息成本、拖拽完成和不确定性校准。
  • 基于大规模截图、重复轨迹和可验证任务的学习被视为改进GUI动作预测的核心路径。
  • 真实交互效果尤其是操作前后屏幕变化和执行动作，正在成为适应与诊断的接地证据。

关键差异

  • 适应对象不同：有的保持模型权重冻结并修改执行框架，有的进行微调或在线RL，还有的仅改变输入关键帧或表示。
  • 监督假设不同：弱标注截图、自动可验证合成任务和人工构建基准各有不同的证据质量和成本。
  • 评测目标不同：任务成功率、子目标完成、成本准确性、拖拽完成、不确定性校准和单步定位各有强调。
  • 交互范围不同：静态桌面或操作系统任务、动态短视频信息流、视频引导工作流、拖拽交互和GUI加CLI混合任务形成不同问题边界。

开放问题

  • 报告增益能否跨操作系统、应用、界面动态和模型类别迁移到所研究基准之外？
  • GUI代理系统哪一部分贡献最大：骨干模型、技能库、执行框架编辑、任务分布还是规划控制器？
  • 如何在多步部署和分布偏移下验证观察控制与不确定性估计的可靠性？
  • 当局限性未说明时缺失哪些证据，消融协议能否区分任务合成、训练和运行时适应的影响？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

59 方法质量 100 近期性 40 可复现性 41 主题相关性

文献综述归纳

研究路线

任务与交互基准构建

将GUI智能体任务从点击式扩展到桌面GUI+CLI、动态短视频、拖拽交互，并定义细粒度子目标或效率评分。

尚未覆盖：平台与应用覆盖仍有限；轨迹级可靠性和观察控制指标尚未标准化。
外部工件与训练驱动的能力提升

通过多模态技能检索、证据驱动harness编辑、可验证RL任务合成或未标注截图弱监督来改进GUI智能体。

尚未覆盖：跨基准与操作系统的迁移仅有部分证据，机制未统一，失败预测和局限性报告不足。
不确定性量化与安全定位

度量GUI定位的后验置信度，并构造共形点击区域以支持选择性预测和空间安全。

尚未覆盖：多步智能体轨迹、跨模型/接口排序迁移和分布偏移下的覆盖保证仍未解决。
交互抽象与观察形式化

形式化动态屏幕和拖拽等先前点击中心工作中缺失的交互单元与评测目标。

尚未覆盖：形式化描述尚未连接到策略学习、安全保证或关于观察控制假设的验证。

研究共性

  • 证据一致认为GUI智能体性能不能只归因于骨干模型，外围harness、技能记忆、训练数据和评测设计对测量结果影响显著。
  • 所有证据都以任务完成或定位准确率为核心指标，多数工作还结合子目标完成、成本准确率或校准置信度等更细信号。
  • 多项工作暴露了聚合分数掩盖的失败模式，如过度/不足观察、UI元素定位错误或交互类型盲区。
  • 2026年证据显示可复现信号参差：代码/数据/工件链接常见，但明确局限声明常缺失。

关键差异

  • 监督与改进信号不同：未标注截图弱监督、可验证合成任务在线强化学习、harness优化和多模态技能检索是不同路线。
  • 知识表示不同：有的保留技能工件中的视觉图形，有的对齐模型输出与截图-动作证据，还有的使用纯文本索引技能文件。
  • 评测粒度不同：一条路线评测单步定位不确定性，另一条评测多步任务轨迹；指标从确定性规则Pass@1到成本准确率不等。
  • 部署与交互范围不同：桌面GUI+CLI、动态短视频、拖拽交互和跨基准冻结harness迁移隐含不同的泛化主张。

开放问题

  • 后验不确定性排序能否从单步定位扩展到多步GUI轨迹，而无需目标特定重排？
  • 哪些假设能解释动态界面上的观察控制失败，并如何在真实部署中检验？
  • 技能库、harness编辑和RL/弱监督带来的提升能否跨操作系统、应用和未见基准分布迁移？
  • 任务成功率、子目标完成、信息效率和校准置信度应如何组合才能定义可靠的GUI智能体行为？

system

Runnable GUI agent systems, frameworks, sandboxes, tool-use platforms, or orchestration layers

59 方法质量 99 近期性 40 可复现性 43 主题相关性

文献综述归纳

研究路线

端到端训练框架与原生 harness 编排

在真实环境中将策略训练为可部署的计算机使用智能体，且无需修改复杂推理 harness。

尚未覆盖：RL 后的错误恢复仍弱；不同 harness 设计下可训练性差异大，跨团队独立部署证据不足。
高效结构化动作策略

在保持 GUI 动作接地的前提下降低解码延迟和参数成本，包括潜空间候选评分和块级扩散。

尚未覆盖：高效策略未完全追平自回归基线，且评估主要集中在内分布基准。
统一 GUI 与代码动作空间

在单一智能体中协调 GUI 交互与代码执行，并通过环境接地监督和在线 RL 优化。

尚未覆盖：报告收益集中在 OSWorld-Verified 和 WindowsAgentArena，更广桌面/网页泛化与明确局限仍缺乏证据。
多模态技能库与按需知识检索

保存视觉和文本任务知识，使智能体按应用加载相关指导。

尚未覆盖：评估基准之外的覆盖范围和真实应用漂移尚未验证；缺失限制说明使边界不清。

研究共性

  • 多模态屏幕与动作接地被视为提升 GUI 和计算机使用智能体的核心。
  • 来自环境、工件或未标注截图的接地监督，优于仅提示或朴素工具组合基线。
  • 即使最终任务完成度尚可，智能体在恢复一致性、个性化生效时机以及排名/过程偏好等细粒度执行属性上仍表现不足。
  • 系统级代码和工件可获得性不均衡，方法论声明易于读取，但独立复现仍存在验证缺口。

关键差异

  • 动作生成范式不同：块级扩散、无解码器潜空间候选评分、GUI 与代码统一动作空间并存。
  • 监督信号来源不同：未标注截图弱监督、应用-工件混合数据、在线环境 RL 和检索式多模态技能。
  • 评测目标不同：参数/延迟/精度权衡、最终基准成功率、恢复一致性以及分阶段个性化探针。
  • 部署假设不同：部分工作在真实 harness 中通过容器化回放训练，部分训练独立多模态模型或为智能体附加技能检索层。

开放问题

  • 高效动作策略能否在保持延迟和参数优势的同时弥合内分布精度差距？
  • 如何将恢复和个性化诊断发现转化为 RL 或监督训练目标，以改进当前较弱的错误恢复和偏好遵循？
  • 现有收益能否跨操作系统、harness 和分布外 GUI 应用泛化，而不局限于 OSWorld-Verified、AndroidControl、WebVoyager 等基准？
  • 独立跨团队复现至少需要哪些代码、工件和环境细节？若干论文缺少明确限制说明，构成验证缺口。

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

62 方法质量 99 近期性 39 可复现性 44 主题相关性

文献综述归纳

研究路线

真实应用基准与细粒度评测

通过多检查点评分、能力注释和成本-准确率等方式，衡量 GUI 智能体在 macOS 桌面任务和动态短视频任务上的表现，而不仅是简单 pass/fail。

尚未覆盖：平台和任务覆盖有限；动态平台智能体仍低于人类水平的成本-准确率；部分工作未提供局限性说明，失败边界未经验证。
可复用计算机使用知识与重复任务加速

通过存储多模态按应用技能，或将成功运行编译为带运行时屏幕检查的状态机重放程序，提高智能体表现或降低执行成本。

尚未覆盖：对未见过应用和工作流的泛化、界面漂移时的回退行为，以及评估广度尚未充分建立。
专用交互 grounding 与任务驱动观测

通过大规模交互数据集或任务相关关键帧提取，处理拖拽式 GUI 操作和视频引导任务中的动态视觉输入。

尚未覆盖：下游 GUI 特定迁移证据不完整：关键帧增益主要在 VideoQA 上报告，拖拽微调主要在一个 VLM 上验证。
可扩展真实网页环境重建

从真实 URL 构建可复用的源对齐网页环境，用于跨多个站点和任务类别的网页智能体评测与微调。

尚未覆盖：需要每个站点初始设置和授权；向更广泛专业网页/软件工作流及长期维护的迁移仍不明确。

研究共性

  • 应用评测正从粗粒度任务成功转向细粒度信号，如子目标完成、能力注释、成本-准确率以及重放/存储时验证。
  • GUI 任务需要更广泛的界面覆盖：桌面 GUI+CLI、拖拽操作、动态信息流、视频引导工作流和真实网页环境，而非仅静态点击场景。
  • 前沿智能体在动态或强观测需求任务上仍表现不足，观察控制和长尾交互 grounding 依然薄弱。
  • 技能库、交互数据集、状态机程序和重建环境等工件可以提升下游智能体的性能或效率。

关键差异

  • 评测目标不同：分别关注真实 macOS 桌面任务、动态短视频成本-准确率、纯拖拽交互、视频引导 GUI 任务或网页环境保真度。
  • 改进机制不同：外部按应用技能、视觉语言预训练/微调、扩散生成、运行时状态机编译、任务驱动关键帧提取或自动环境构建。
  • 成功指标不同：Pass@1、子目标完成、成本-准确率、重放加速、存储时任务保留和下游基准提升不能直接比较。
  • 部署假设不同：有些方法假设实时智能体每步调用模型并保留回退，另一些将运行编译为无需每步语言模型调用的程序，带来不同的延迟和适应性权衡。

开放问题

  • 什么机制能让 GUI 智能体具备显式观察控制，从而在持续更新的界面中既不过度观察也不观察不足？
  • 技能库、拖拽数据集、重放程序、关键帧提取和重建网页环境能否跨应用、平台、语言和专业软件迁移？
  • 成本-准确率、子目标完成等细粒度基准指标是否与真实办公自动化和软件操作效率一致？
  • 多项工作缺失局限性说明，工件和可复现信号差异明显；哪些失败模式和鲁棒性边界仍未验证？
  • 拖拽微调或视频关键帧训练等专用训练收益，能否在受测 VLM 和基准之外的下游计算机使用任务上复现？

关键差异

  • 干预点不同：关键帧选择、执行harness编辑、在线强化学习训练、上下文作为动作策略、密集监督、潜在评分或后验不确定性校准。
