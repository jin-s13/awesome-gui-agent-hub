研究路线

真实GUI/OS基准与交互任务设计

为桌面、动态短视频、拖拽式和视频引导计算机使用场景建立更贴近环境的任务分布，使能力比较不局限于点击/输入类基准。

尚未覆盖：覆盖仍偏环境或动作类型；跨OS、跨应用、跨界面和更长时程真实场景泛化尚未被证据确认。
通过技能、监督和任务合成提升智能体能力

用多模态技能工件、未标注截图弱监督、可验证RL任务生成和任务感知关键帧选择缓解视觉定位与策略学习短板。

尚未覆盖：证据集中在选定基准；未见应用泛化、不同数据/算力预算下的效率以及动态界面鲁棒性的充分验证。
细粒度指标、诊断与不确定性压力测试

在总体成功率之外提供子目标完成、成本-准确性信息效率和GUI定位的后验不确定性/共形安全诊断。

尚未覆盖：代理指标与用户决策效用尚未对齐；跨模型层级和接口的UQ迁移较弱；多步轨迹不确定性未被覆盖。
跨模型基线与复现工件规范

通过多框架/模型对比以及在部分工作中发布确定性评分或分析工件，使结果更可审计。

尚未覆盖：若干论文缺少可见局限性或完整代码/数据集/仓库信号，跨实现、算力预算和基准版本的结论稳定性仍不确定。

研究共性

  • 真实任务分布能暴露粗粒度点击/输入评测遗漏的缺陷。
  • 子目标完成、成本-准确性、不确定性等细粒度指标提供总分之外的诊断价值。
  • 前沿VLM智能体在动态观察、多步执行和非点击交互方面仍存在明显不足。
  • 规模化任务合成、弱监督和多模态技能检索是降低标注成本或改善视觉定位的有前景方向。
  • 基准测试需要受控环境和确定性/可复现评分来支持审计。

关键差异

  • 交互空间：拖拽、桌面GUI+CLI、动态短视频与视频引导任务强调不同能力边界，难以直接比较。
  • 评测目标：单步GUI定位、多步任务完成和带效率约束的任务完成采用不同成功定义。
  • 监督与适应：未标注截图弱监督、可验证在线RL、多模态技能库和关键帧提取依赖不同数据与算力假设。
  • 指标侧重：Pass@1、子目标完成、成本-准确性和共形不确定性反映不同可靠性与有用性视角。
  • 复现姿态：部分工作提供规则评分或UQ记录，部分缺失局限性与工件信号，使跨论文可审计性不均。

开放问题

  • 细粒度基准指标能否在桌面、网页、移动端和动态短视频环境间无需目标特定校准而迁移？
  • 不确定性排名方法为何在模型系列内迁移较好，但在模型层级和可观察接口之间迁移较差？
  • 智能体应如何在动态界面中学习或调节观察，以避免过度观察和观察不足？
  • 技能检索、弱监督和可验证RL的收益能否泛化到报告基准之外的未见应用或操作系统？
  • 当若干条证据缺少代码、数据集、指标、基线或局限性信号时，至少需要哪些工件才能验证基准结论？

研究路线

GUI 定位与动作空间评测

定义跨点击、拖拽、GUI+CLI、视频引导和动态短视频界面的动作预测与定位评测面

尚未覆盖：评测常限于单一平台或单步；向多步轨迹、未见界面和不同模型类别的迁移仍无证据
GUI 策略的训练数据合成与弱监督

通过可验证合成任务生成、未标注截图学习或交互特定监督数据降低人工标注成本

尚未覆盖：任务合成、RL、数据规模与模型能力的贡献未分离；部分工作缺少明确限制或完整可复现细节
推理时上下文与观察控制

通过上下文压缩、任务相关关键帧选择或联合成本-准确性评分改善长时域与动态界面表现

尚未覆盖：这些机制能否纠正过度/不足观察缺陷并从特定基准环境泛化尚未被证明
面向定位的不确定性与细粒度评估

揭示相似成功率掩盖的子目标差异，并校准不确定性或共形点击区域以支持可靠性判断

尚未覆盖：发现主要限于单步定位；跨模型/接口的不确定性排序迁移较弱，共形覆盖在分布或接口偏移下退化

研究共性

  • 当前 GUI 代理在动态或长时域任务上仍低于人类水平，仅看总体成功率会掩盖有意义的失败结构。
  • 动作定位与预测越来越多通过特定任务的子目标完成、成本-准确性、校准空间覆盖等指标来评估，而非只看聚合成功。
  • 多项工作都追求样本或标注效率，路径包括可验证合成任务、截图弱监督、关键帧提取、上下文压缩和交互特定数据集。
  • 证据基础存在验证缺口：不少高排名工作给出强结果，但未提供局限性说明，或工件与可复现信号有限。

关键差异

  • 评测目标不同：一些工作优化任务成功和子目标完成；一些优化有限观察下的成本-准确性；另一些评估不确定性排序与共形点击安全。
  • 交互设置不同：静态 macOS 桌面并含 GUI+CLI、长时域移动端、动态短视频、视频引导和拖拽特定动作空间，构成不同边界。
  • 改进路径不同：在线 RL 加可验证任务生成、未标注数据弱监督、拖拽/交互数据监督微调，以及推理时上下文/关键帧管理。
  • 评测假设不同：基于规则的任务真值评分与事后不确定性校准、UQ 排序暗示不同的泛化与部署约定。

开放问题

  • 已报告的 OSWorld、ScienceBoard、MemGUI-Bench、MacAgentBench 和短视频场景提升，能否迁移到未见操作系统、界面类型或闭源模型层级？
  • macOS 与在线 RL 上测得优势中，多少来自技能库、任务先验、框架设计或合成数据，而非所述方法本身？
  • 动态界面中的过度观察与观察不足，能否被主动上下文管理或关键帧选择真正纠正，还是需要新的观察控制学习目标？
  • 单步不确定性排序和共形定位结果，能否扩展到多步代理轨迹以及内部状态不可访问的模型？

theory

Formal analysis, task abstractions, interaction theory, or reliability/safety framing for GUI agents

62 方法质量 99 近期性 39 可复现性 49 主题相关性

文献综述归纳

研究路线

交互机制形式化与基准边界划定

为桌面、动态短视频和拖拽等交互提供任务抽象、评分规则和故障模式证据，包括细粒度多检查点和成本准确性信号。

尚未覆盖：覆盖范围受限于所选平台和交互类型；形式化假设与真实模型行为之间缺少直接匹配，部分工件不可见。
规模扩展与训练数据效率

通过可验证任务合成、在线强化学习、未标注截图弱监督和视觉上下文切分降低对昂贵标注或密集奖励的依赖。

尚未覆盖：证据中局限性基本缺失，且这些方法能否预测失败并迁移到报告基准之外仍缺少直接验证。
面向长程控制的技能与上下文管理

通过检索多模态技能工件或主动发出的上下文管理动作改进长程任务和UI接地工作流，保持状态紧凑且信息充分。

尚未覆盖：报告增益依赖特定基础模型和框架；分布外泛化仅部分测试，跨应用或界面变化的鲁棒性不明确。
GUI接地的可靠性量化

对后验不确定性量化和共形点击区域进行基准评测，区分稳定的开源权重UQ族与较弱的跨层级迁移。

尚未覆盖：评测仅限于单步可执行接地而非多步智能体轨迹，且在校准/测试或界面不匹配下覆盖度下降。

研究共性

  • 研究将GUI智能体视为基于屏幕或UI状态的视觉语言策略，并以任务成功和更细粒度指标而非仅通过率来评测。
  • 点击式评测不足以代表真实计算机使用，因此需要覆盖GUI/CLI混合、动态内容、拖拽交互和长程上下文。
  • 方法论文普遍通过基准任务套件上的基线对比论证改进，并将增益归因于精选数据、技能库或上下文机制，而非仅靠架构变化。

关键差异

  • 评测目标不同：有的衡量通用桌面任务完成，有的关注动态内容成本准确性、拖拽接地、不确定性排序或长程移动控制。
  • 监督与训练机制不同：可验证强化学习合成、未标注截图弱监督、检索式多模态技能和监督式上下文动作各自依赖不同数据假设。
  • 部署场景差异明显，包括macOS桌面、浏览器短视频环境、移动设备和单步接地，意味着不同的可观测性和动作空间。
  • 能力导向工作优先考虑成功率提升，可靠性导向工作优先考虑选择性不确定性排序和共形空间覆盖，反映出前沿性能声明与安全评测之间的张力。

开放问题

  • 不同任务形式化和指标选择会如何改变模型排名或训练目标，尤其是在平台、交互类型和模型层级变化时？
  • 可验证任务合成和弱监督是否能预测失败并迁移到报告基准之外的环境？
  • 不确定性量化排名能否跨模型类别和可观察接口迁移，而无需针对目标重新排序？
  • 当基础视觉语言模型或智能体框架改变时，哪种上下文管理或多模态技能表示能保持长程可靠性？

研究路线

端到端GUI/计算机使用智能体训练与编排框架

把策略转化为可在网站、桌面和harness中执行多步任务的智能体；通过弱监督、在线RL或可验证奖励降低标注数据需求。

尚未覆盖：错误恢复在训练后仍然较弱；harness设计影响可训练性；跨环境部署与独立复现尚未在报告基准之外得到验证。
面向GUI智能体的多模态技能与记忆增强

通过存储结构化视觉/文本技能工件或动作接地图像裁剪，改善UI接地与工作流验证，而非仅依赖完整截图。

尚未覆盖：跨应用和操作系统泛化；离线评测与真实交互的差异；不同记忆表示的独立比较仍然缺失。
GUI过渡与失败模式的诊断评测

测量模型是否理解动作引起的状态变化、来源跟踪和任务相关GUI过渡，而非只评估端到端成功。

尚未覆盖：基准为离线且局限于Linux或预定义动作类型；步骤级诊断尚未建立对异步、实时GUI交互的预测效度。
计算机使用智能体的安全与红队基础设施

审计浏览器和编码表面的提示注入与技能注入抵抗力，并检查先前攻击结果是否可复现。

尚未覆盖：仅测试手工攻击模板；未复现RL优化注入字符串；安全加固呈现领域条件性，无法跨表面泛化。

研究共性

  • 当前系统普遍强调多模态视觉接地，依赖截图和图像表示，而非仅依赖DOM或可访问性元数据。
  • 训练与评测正在转向可执行的智能体循环：策略回滚、轨迹级奖励和真实环境交互，而不是静态单步预测。
  • 记忆、上下文管理和技能/工具检索被视为多步GUI任务性能的核心组件。
  • 开源框架试图降低数据和基础设施成本，同时匹配更大的专有智能体，但验证多局限于基准。

关键差异

  • 交互表示不同：部分系统仅通过原生截图和键盘鼠标操作，另一些包装harness或调用工具，影响可控性与可训练性。
  • 监督与数据规模不同：未标注截图的弱监督和极小标注预算，对比云规模可验证回滚与在线RL。
  • 评测重点不同：端到端成功指标、步骤级过渡理解和对抗攻击成功率并存，结果难以直接比较。
  • 记忆设计不同：全图视觉记忆、动作接地局部裁剪和分层多模态技能库对保留何种视觉上下文做了不同假设。

开放问题

  • 强化学习训练的GUI智能体是否真能显著改善错误恢复，当前证据显示恢复能力仍然较弱？
  • 安全加固是否能在应用域间迁移，尤其是从浏览器任务迁移到编码或工具使用任务？
  • 离线步骤级GUI过渡诊断能否预测异步时序和延迟下的真实端到端可靠性？
  • 这些系统在操作系统、动作词汇和独立复现的基础设施设置上泛化如何？

application

Domain applications of GUI agents, such as office automation, mobile apps, web tasks, software operation, or professional tools

64 方法质量 99 近期性 37 可复现性 50 主题相关性

文献综述归纳

研究路线

真实桌面与跨平台计算机使用基准评测

在真实桌面应用及网页、移动、桌面跨平台任务上，以细粒度结果衡量 GUI 智能体能力，而不只看最终成功。

尚未覆盖：证据多局限于单平台或单任务；细粒度桌面指标能否跨操作系统、应用和真实专业工作流迁移尚未验证。
多模态技能库与可复用任务程序

通过检索先前应用知识或将成功运行编译为快速重放，改善计算机使用智能体，降低重复推理成本并以视觉工件支撑动作定位。

尚未覆盖：视觉技能收益和重放加速仅在选定基准上验证；陈旧或错配屏幕、未见应用，以及可复用工件能否覆盖动态 UI 变化仍未解决。
动态、视频引导与观察敏感的 GUI 任务

评估和改善界面内容随时间变化或依赖视频和关键帧提供指令的智能体，包括观察成本与任务准确性的权衡。

尚未覆盖：当前智能体缺乏观察控制，常过度观察或观察不足；关键帧提取收益多来自视频问答，尚未证明能广泛迁移到 GUI 智能体任务。
专业化交互定位与执行纠错

覆盖拖拽等非点击中心交互，并通过历史感知、视觉基础的评判器在执行前拦截错误。

尚未覆盖：拖拽和评判器结果仅在有限测试集上展示；将专业化交互定位与跨平台评判器泛化及真实失败代价相结合的证据不足。

研究共性

  • 视觉基础在多类任务中都很关键：截图、UI 元素或视觉技能工件对 GUI 智能体性能和失败诊断具有核心作用。
  • 需要比最终成功更细粒度的评测，包括子目标完成度、成本-准确性和受控条件下的良性召回。
  • 真实或高保真模拟应用环境是必要的，因为纯文本或静态基准会遗漏执行错误、观察行为和交互覆盖。
  • 当前智能体表现出共同失败模式：规划尚可，但在定位、观察控制或重复任务效率上不可靠。

关键差异

  • 工作面向不同领域和交互模式，从静态桌面或网页任务到动态信息流、拖拽交互、视频引导任务和安全敏感导航，所需观察和动作模型不同。
  • 干预方式不同：一类提供外部技能检索，一类编译重放，一类加入评判器，另一类选择任务相关关键帧，分别针对不同瓶颈。
  • 评测目标不同：聚合任务准确率、Pass@1、成本-准确性、子目标完成度或良性召回，导致难以直接比较。
  • 部分工作仅提供基准而无新干预，部分工作提出方法级改动，因此证据在收益究竟来自模型、框架还是外部记忆或技能组件上并不一致。

开放问题

  • 技能检索、重放、评判器和关键帧收益能否跨操作系统、应用及动态变化界面迁移？
  • 在流式或视频化界面中，当过度观察和观察不足都会降低表现时，智能体应如何平衡观察成本与准确性？
  • 在 Pass@1 之外，哪种评测信号——子目标完成度、成本-准确性、良性召回——最能预测真实桌面、移动和专业工作流的可靠性？
  • 当前专业化基准对未见应用、语言、对抗内容以及 URL 和信誉元数据等现实线索的鲁棒性如何？
  • 当前应用基准和方法是否提供了足够代码、数据、基线和局限性证据以支持复现与泛化声明？

研究共性

  • 基准驱动评测是主导证据模式，通常以成功率、排序迁移或攻击成功率判断GUI/计算机使用智能体。
  • 基于VLM的智能体和评估器处于核心，但在领域、界面或分布偏移下可靠性下降。
  • 训练类工作越来越多依赖可验证或合成任务以及自主奖励信号，而不仅依赖人工标注演示。
  • 稳健泛化仍然困难：一个基准、模型层级或领域的发现往往难以迁移到另一个。
  • 证据包区分流行度或优先阅读信号与方法学、可复现性信号；若干高分论文缺少局限说明或工件证据，属于验证缺口。

关键差异

  • 评测对象不同：单步可执行grounding、多步浏览器或移动任务、欺诈判断或视频引导GUI控制。
  • 监督与训练方式不同：可验证任务合成加在线RL、监督式上下文管理、噪声校正评估器奖励RL，或完全无训练。
  • 交互模式不同：静态截图grounding、长时移动UI、浏览器安全、视频关键帧和多模态教程生成。
  • 安全与不确定性结论存在张力：UQ排序在模型内迁移强而跨层级弱；浏览器提示注入抵抗强而编码域技能注入脆弱。
  • 基准协议的信息约束不同：欺诈检测隐藏URL与信誉，安全审计使用掩码协议，RL使用最终截图奖励。

开放问题

  • 应优先解决哪个部署缺口：不确定性迁移、长时上下文、领域条件安全，还是奖励噪声？
  • UQ排序与安全抵抗结论能否在模型层级和界面之间免目标重评迁移？
  • 当任务和指标不同时，OSWorld、ScienceBoard、MemGUI-Bench、MobileWorld和视频引导基准上的成功率有多大可比性？
  • 基于单步grounding或仅浏览器安全的结论能否推广到多步、跨领域和真实GUI工作流？
  • 正式GUI智能体综述应采用哪些系统纳入和质量标准，当前证据包主要为原始研究而非完整综述文本？
