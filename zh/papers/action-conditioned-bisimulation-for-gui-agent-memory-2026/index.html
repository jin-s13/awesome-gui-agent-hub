深度分析

创新点

  • 将记忆合并规则定义为动作条件互模拟，作用于冻结GUI智能体在行动中填充的经验预测状态图。
  • 仅当共享动作在可供性标签下产生一致的结果与后继块时才合并状态，完全排除观测相似性。
  • 无需训练，避免为记忆合并学习相似性模型或预测模型。
  • 替换现有结果-价值记忆的合并规则，实现可隔离该合并规则的闭环比较。

方法

该方法从冻结智能体的交互中构建经验预测状态图，并使用动作条件互模拟准则合并状态：仅当共享动作在可供性标签下产生一致结果和一致后继块时，状态才被合并。该规则替换现有结果-价值记忆中的合并规则，并在MiniWoB++上进行闭环评估，与无记忆智能体、采用相同探索性绕行的对照组、先前后继表示合并以及同一标准但不含动作条件的对照组进行比较。

关键结果

在MiniWoB++上，所提出的记忆相比无记忆智能体提高了成功率；而采用相同探索性绕行、先前后继表示合并以及同一标准但不含动作条件的对照组均未带来变化。
