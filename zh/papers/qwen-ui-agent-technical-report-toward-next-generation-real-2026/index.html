深度分析

创新点

  • 统一动作空间，将GUI操作与CLI执行交织，在单个模型轮次中生成批处理动作
  • AutoResearch风格的数据飞轮，智能体自主构建任务和环境、诊断失败并规划后续迭代
  • 在线RL训练超过100步的轨迹，利用超过10,000个并发环境加速回滚
  • 轻量级监测层支持跨移动和电脑的主动服务启动与有状态工作流
  • 面向真实世界设计，覆盖移动、电脑使用、网页和DeepSearch环境，集成沙盒和大规模真实设备移动运行时

方法

Qwen-UI-Agent使用多样化的沙盒环境和大规模真实设备移动运行时进行训练。它采用统一动作空间，将GUI和CLI动作交织并生成批处理，以及AutoResearch风格的数据飞轮，智能体可自主构建任务、诊断失败并规划迭代。在线RL扩展到长轨迹（100+步），拥有超过10,000个并发环境；一个监测层提供主动服务启动和跨平台有状态工作流。

关键结果

在移动使用上，Qwen-UI-Agent取得最优性能：MobileWorld 82.1%，MobileWorld-Real 92.2%，AndroidDaily 97.5%。在电脑使用上取得有竞争力的结果（OSWorld-Verified 79.5%，OSWorld-v2部分进展40.0%），浏览器/GUI定位得分（WebArena 73.6%，ScreenSpot-Pro 81.5%），与Opus 4.8、Gemini 3.1 Pro和GPT-5.6 Sol等前沿模型相比。
