深度分析

创新点

  • 提出了 PrefDiag-Bench，一个用于诊断移动 GUI 智能体个性化失败的基准，而非仅评估整体任务成功率。
  • 将用户偏好分为五类，刻画偏好如何改变执行策略。
  • 提供了包含 1,664 个探针的分阶段诊断框架，追踪偏好应在何时生效以及失败发生在何处。
  • 在显式用户画像和行为记忆日志两种用户情境下，评估了十一个 GUI 智能体系统，包括端到端智能体和智能体工作流。

方法

PrefDiag-Bench 将五类偏好分类与包含 1,664 个探针的分阶段诊断框架相结合，以追踪偏好生效时机和失败位置。它评估了包括端到端智能体和智能体工作流在内的十一个 GUI 智能体系统，在两种用户情境下：显式用户画像和行为记忆日志。研究比较了非个性化和偏好个性化任务上的表现，并通过提供相关证据的受控干预来检验能力瓶颈。

关键结果

现有智能体在非个性化任务上完成率较高，但在偏好个性化任务上表现大幅下降；最佳模型 Seed-2.0-Pro 在显式用户画像下的 Process 偏好上仅达到 47.17%，且智能体尤其难以处理 Ranking 和 Process 偏好。分析揭示了从用户历史中选择相关证据和识别偏好生效时机两个瓶颈；提供相关证据的干预可将端到端任务成功率提高最多 7.06%。
