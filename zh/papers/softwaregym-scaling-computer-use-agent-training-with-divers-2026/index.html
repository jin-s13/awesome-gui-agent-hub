Strengths include scalable environment synthesis and empirical validation; weaknesses are limited visible detail on trajectory collection and potential synthetic-domain bias.

深度分析

创新点

  • SoftwareGym automated pipeline for synthesizing GUI software environments with diverse interfaces, executable functionality, and runtime-verified behavior.
  • Integration of structurally diverse design generation, runnable application realization, and GUI evaluation with iterative repair to ensure functional reliability.
  • SoftwareGym-Bench, a 120-task evaluation suite spanning twelve application categories.
  • Use of trajectories collected from synthesized software environments for computer-use agent training, showing transferability to out-of-domain benchmarks.

方法

SoftwareGym generates structurally diverse GUI designs, realizes them as runnable applications, and uses GUI evaluation with iterative repair to ensure functional reliability. The authors synthesize 182 applications across twelve categories and construct SoftwareGym-Bench, a 120-task evaluation suite spanning the same twelve categories. Trajectories collected from these environments are then used for computer-use agent training, with evaluation on SoftwareGym-Bench and OSWorld.

关键结果

Across 182 synthesized applications, the pipeline achieves a mean GUI task pass rate of 91.5%. Training with SoftwareGym trajectories improves Pass@3 on the out-of-domain OSWorld benchmark from 41.39% to 56.97%, and the resulting model achieves 40.0% on SoftwareGym-Bench.

局限性

  • Native application environments require substantial construction and integration effort, limiting application coverage and increasing the risk of application-specific overfitting.
  • Browser-hosted environments provide limited interaction depth and workflow complexity.
  • The abstract does not state limitations specific to SoftwareGym itself.
