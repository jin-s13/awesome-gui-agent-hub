深度分析

创新点

  • Affora设计系统在保留视觉自由和熟悉的人类工作流程的同时，支持人类与机器读者。
  • 基于三项受控研究，提供从单个组件到完整网站的指导。
  • 面向代理友好界面的可复用实现与可执行检查。
  • 采用共享界面连接用户体验与代理体验，无需单独的代理专用界面。

方法

三项受控研究考察组件实现、视觉变化和交互设计原则，其发现为Affora的指导和可执行检查提供依据。随后在独立编写的界面上评估，并通过一个工作流案例补充交互成本证据。

关键结果

代理性能取决于界面表示中可用的交互含义；当该含义被保留时，仍可进行大幅视觉变化。在独立编写的界面上评估显示，在Affora弥补现有缺陷之处有增益，但在缺陷不存在或超出其覆盖范围时效果有限；工作流案例初步表明交互成本降低。

局限性

  • 在现有界面缺陷不存在或超出Affora覆盖范围时，效果有限。
  • 工作流案例仅提供交互成本降低的初步证据。
