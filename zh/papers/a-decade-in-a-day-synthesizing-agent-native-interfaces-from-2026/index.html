深度分析

创新点

  • 提出了 DeskIF-Bench，一个涵盖六款桌面应用中 255 个工件验证任务的基准，用于评估智能体对桌面软件界面的使用。
  • 将跨版本的软件演化作为界面变化的自然来源，同时保持任务、智能体和验证器固定。
  • 识别出与智能体性能相关的三个界面属性：可发现性、粒度性和可观测性。
  • 开发了 ANIS，一个从已安装应用能力中合成智能体原生界面的框架，包括原子界面和目标级命令。

方法

本文提出了包含六款桌面应用中 255 个工件验证任务的 DeskIF-Bench，并在保持任务、智能体和验证器固定的情况下改变软件版本，以衡量界面变化如何影响智能体性能。轨迹分析识别出相关的界面属性。随后开发了 ANIS，并在八款应用的 368 个任务上进行评估，使用成功率和 token 用量指标比较了合成的原子界面和目标级命令与原生 SDK 使用的性能。

关键结果

在两种模型和六款应用上，最新软件版本始终优于最旧版本。原子界面相比原生 SDK 使用，使 DeepSeek V4 Flash 的成功率提高 3.8 个百分点，使 Claude Haiku 4.5 提高 3.5 个百分点，同时将在线 token 使用量减少约 73%；目标级命令进一步将成功率分别提升至 74.5% 和 67.4%。
