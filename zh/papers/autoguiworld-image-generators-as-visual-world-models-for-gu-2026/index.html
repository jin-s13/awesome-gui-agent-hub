深度分析

创新点

  • AutoGUIWorld 框架利用图像生成器作为视觉世界模型，无需部署或运行相应软件环境即可合成 GUI 交互轨迹。
  • 将图像生成器的视觉先验与规划器的任务知识相结合，以生成任务、原子动作及其预期的视觉结果。
  • 从操作系统上下文、视觉外观和界面状态的结构化规范中采样初始 GUI 场景，并基于这些场景生成任务。
  • 使用 action grounding 和 transition 级质量过滤，构建包含 79,266 个跨 Ubuntu、Windows、macOS 和 Chrome 的空间标注步骤级训练样本的大型数据集。

方法

AutoGUIWorld 从操作系统上下文、视觉外观和界面状态的结构化规范中采样初始 GUI 场景，并基于这些场景生成任务。规划器指定原子动作及其预期的视觉结果，图像生成器则迭代地编辑当前截图以生成后续观测。通过 action grounding 和 transition 级质量过滤，生成 79,266 个跨 Ubuntu、Windows、macOS 和 Chrome 的空间标注步骤级训练样本。

关键结果

在 AutoGUIWorld 轨迹上微调 Qwen3.5-35B-A3B 将 OSWorld 的平均任务分数从 33.0% 提升至 40.8%，并将 ScienceBoard 的任务成功率从 14.0% 提升至 32.2%。
