深度分析

创新点

  • 对基于VLM的GUI智能体中的记忆模态进行系统性研究，揭示偏好的记忆表示强烈依赖于交互步骤。
  • SwitchMem，一种在每个交互步骤动态选择文本或视觉记忆表示的路由框架。

方法

本文在多个GUI基准上研究了基于VLM的GUI智能体中的记忆模态，并提出了SwitchMem——一种在每一步选择文本或视觉记忆表示的路由框架。SwitchMem与使用静态记忆表示的记忆增强基线在三个GUI基准上进行了评估。

关键结果

在多个GUI基准上，偏好的记忆表示强烈依赖于步骤。SwitchMem在三个GUI基准上均优于依赖静态记忆表示的记忆增强基线。
