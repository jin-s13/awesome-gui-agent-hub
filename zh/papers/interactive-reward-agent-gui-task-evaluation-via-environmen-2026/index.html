深度分析

创新点

  • 交互式奖励代理（IRA）及其“先提出后验证”框架，从执行后环境中获取并验证证据
  • 超越截图的環境状态验证，通过调用系统工具、应用程序工具和GUI工具
  • GUI-RewardBench，一个包含321个GUI任务轨迹、覆盖10个Ubuntu桌面应用程序类别的基准测试
  • 证明IRA可作为GUI代理强化学习的有效奖励信号，提升OSWorld成功率

方法

IRA首先根据指令和执行后环境提出任务完成条件，然后通过调用系统工具、应用程序工具和GUI工具进行验证。评估使用新构建的GUI-RewardBench（321个轨迹，10个Ubuntu应用类别），并与现有评估基线对比。强化学习实验中使用IRA作为奖励信号训练GUI代理。

关键结果

IRA在GUI-RewardBench上达到86.9%的准确率，优于现有评估基线。作为强化学习奖励信号时，帮助GUI代理在OSWorld上达到34.0%的成功率。
