深度分析

创新点

  • 通过五个问题和三个地平线定义个人智能体概念。
  • 基于公开记录和生产环境提示词重构Meta Muse的设计，并逐条标注来源。
  • 提出nanoMuse，一个采用GPL-3.0许可证的开源个人智能体，可运行在用户拥有的每台设备上。
  • 提出一种架构：通过自托管relay共享对话，Sentinel门控动作，人类可读的基于文件的记忆，以及用户自选模型。

方法

本文首先用五个问题和三个地平线定义个人智能体；然后利用公开记录和一份生产环境提示词分析Meta Muse，并按来源标注论断；最后介绍nanoMuse系统设计，包括手机和电脑上的设备级hands、共享relay、Sentinel动作门控、基于文件的记忆、模型选择以及规模与成本的估算。

关键结果

摘要未报告定量实验结果。主要结果是nanoMuse本身：一个采用GPL-3.0的开源个人智能体，拥有手机和电脑上的hands、经由relay的共享对话、Sentinel门控动作、可读文件记忆和用户自选模型，并给出规模与成本的估算。

局限性

  • 规模与成本仅为估算值，而非实测结果。
  • 带来源的记忆、针对hands的评测套件以及开放的模型仍属于路线图事项，而非已完成贡献。
  • 对Muse的分析基于公开记录和生产环境提示词，因此未公开或未记录的实现细节仍无法验证。
