深度分析

创新点

  • Spatial Credit Assignment uses screen coordinates of sampled clicks to refine group-relative credit for GUI agent reinforcement learning.
  • For groups containing both successes and failures, SCA predicts each held-out response's reward from the other responses and uses the prediction residual to adjust credit.
  • When all sampled clicks fail, SCA orders them by distance to the annotated target to provide a relative training signal.
  • Spatial references are used only to construct the training update, leaving the deployed policy unchanged.

方法

SCA refines group-relative reinforcement learning for GUI action prediction by using screen coordinates of sampled clicks to adjust credit, predicting held-out reward residuals in mixed success/failure groups and using distance-to-target ordering in all-failure groups. The approach is evaluated in a controlled synthetic study on update error and directional alignment with the exact return gradient, and on GUI grounding and offline action-prediction benchmarks against reinforcement-fine-tuned models.

关键结果

SCA improves GUI grounding across professional domains and achieves the strongest results among reinforcement-fine-tuned models on most offline action-prediction metrics, with consistent gains across the reported GUI suites.

局限性

  • The abstract does not state explicit limitations of the proposed SCA method; it notes that existing group-relative RL treats spatially different failed clicks as identical and provides no relative signal when all sampled clicks fail.
