Deep Analysis

Innovations

  • CLASHarness: a controllable framework for generating verifiable multi-agent conflicts in computer use.
  • Hierarchical scenario planning combined with an eight-step verified micro-pipeline.
  • Pre-committing decisive visual facts before rendering and compiling hybrid code and semantic graders from executed reference trajectories, guaranteeing solvability by construction.
  • A benchmark of 600 multi-round tasks and an evaluation of 15 frontier models identifying three core conflict-resolution bottlenecks.

Methodology

CLASHarness uses hierarchical scenario planning and an eight-step verified micro-pipeline to generate verifiable multi-agent conflicts, pre-committing decisive visual facts before rendering and compiling hybrid code and semantic graders from executed reference trajectories so every task is solvable by construction. The benchmark comprises 600 multi-round computer-use tasks, and 15 frontier models are evaluated on behaviors such as verifying ground truth and completing closing actions.

Key Results

Evaluating 15 frontier models reveals that weaker models blindly follow misleading sub-agent outputs while stronger models inspect visual evidence to verify ground truth; resolving conflicts is much harder than finding them, with fixing system state dropping task success significantly; and even frontier models fail over 58% of closing actions, often forgetting to release shared locks or hand off tasks.

Limitations

  • The abstract does not state explicit limitations of CLASHarness itself.
  • It notes that existing manual authoring cannot scale across complex systems and that unconstrained LLM generation produces narrative drift, answer leakage, and unsatisfiable rubrics.
