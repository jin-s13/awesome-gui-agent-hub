Deep Analysis

Innovations

  • Unified action space that interleaves GUI operations with CLI execution, generating batched actions in a single model turn
  • AutoResearch-style data flywheel where agents construct tasks and environments, diagnose failures, and plan subsequent iterations autonomously
  • Online RL training on trajectories exceeding 100 turns using over 10,000 concurrent environments for rapid rollout
  • Lightweight harness layer enabling proactive service initiation and stateful workflows across mobile and computer
  • Real-world centric design spanning mobile, computer-use, web, and DeepSearch environments, integrating sandbox and large-scale real-device mobile runtime

Methodology

Qwen-UI-Agent is trained using diverse sandbox environments and a large-scale real-device mobile runtime. It employs a unified action space interleaving GUI and CLI actions with batched generation, and an AutoResearch-style data flywheel that uses agents to self-construct tasks, diagnose failures, and plan iterations. Online RL scales to long trajectories (100+ turns) with over 10,000 concurrent environments; a harness layer adds proactive service initiation and cross-platform stateful workflows.

Key Results

On mobile use, Qwen-UI-Agent sets state-of-the-art with 82.1% on MobileWorld, 92.2% on MobileWorld-Real, and 97.5% on AndroidDaily. It achieves competitive computer-use scores (79.5% OSWorld-Verified, 40.0% partial-progress OSWorld-v2) and browser/GUI grounding scores (73.6% WebArena, 81.5% ScreenSpot-Pro) against frontier models like Opus 4.8, Gemini 3.1 Pro, and GPT-5.6 Sol.
