OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use

arXiv 2026 54.9 method

TLDR

OpenGCUA is an open full-stack project for generalist computer-use agents; code execution and model-driven decision transfer improve OSWorld-v2 scores across eight models.

Reasoning

The paper introduces a promising open stack for generalist computer-use agents, with empirical gains across multiple models and reduced task steps. However, it is an ongoing project and the abstract lacks detailed evidence on real-device harness performance and limitations.

Deep Analysis

Innovations

  • Introduces OpenGCUA, an open full-stack project for generalist computer-use agents, including implementation, prompts, evaluation trajectories, a real-device harness, and a cross-device SDK.
  • Defines the generalist computer-use agent (GCUA) as a system in which the model chooses how to observe, act, and organize work across visual and programmatic interfaces.
  • Uses code execution as a core agent design feature, allowing intermediate results to determine subsequent operations and letting models apply programming skills directly to computer interaction.
  • Proposes harness-to-model decision transfer, moving selected observations and task-state decisions from fixed harness rules to the model.
  • Releases preliminary real-device harness and cross-device SDK, addressing real-device challenges and providing a common programming interface across computers, mobiles, and browsers.

Methodology

OpenGCUA is evaluated on OSWorld-v2 across eight models, including GPT-6 Astra and Claude Opus 5, comparing its full configuration against batched GUI-only execution using mean partial score and reported steps per task. The project also introduces a real-device harness and cross-device SDK, with preliminary real macOS tasks used to compare reported reasoning tokens between Qwen3.8-Max and GPT-6 Astra.

Key Results

On OSWorld-v2, the full OpenGCUA configuration improves task scores across all eight evaluated models, raising mean partial score by +19.6 points and reducing reported steps per task by an average of 53.0% relative to batched GUI-only execution. Across four real macOS tasks, selected Qwen3.8-Max runs use 19.4 times as many reported reasoning tokens as GPT-6 Astra.

Limitations

  • The project is ongoing and this report presents only the first release, so the full stack is not yet complete.
  • The real-device harness and cross-device SDK are released as preliminary versions.
  • Real-device evaluation is limited to four real macOS tasks and selected runs, so the efficiency findings may not generalize broadly.
  • Benchmarks such as OSWorld-v2 do not fully capture real-device challenges.
