Deep Analysis

Innovations

  • Introduces DynaRev, a benchmark of 181 tasks for evaluating web agents under dynamic goal revision rather than fixed pre-specified goals.
  • Uses semantic milestones to deliver goal revisions at task-defined stages.
  • Covers three revision types: additive revisions, unconditional overrides, and runtime-conditioned overrides.
  • Evaluates agents along correctness, responsiveness, and efficiency via trajectory-grounded evaluation.

Methodology

DynaRev is a benchmark of 181 web tasks where goal revisions are delivered through semantic milestones at task-defined stages. It evaluates web agents on correctness, responsiveness, and efficiency using trajectory-grounded evaluation. The study evaluates five models and analyzes milestone timing, effects of dynamic delivery, and revision-handling strategies including instruction rewriting and browser resets.

Key Results

Evaluated agents often satisfy only part of the task requirements, with performance varying across task sources, revision types, and models. Revision handling shows gains from instruction rewriting while preserving browser state and losses from browser resets, alongside mixed effects of dynamic delivery.
