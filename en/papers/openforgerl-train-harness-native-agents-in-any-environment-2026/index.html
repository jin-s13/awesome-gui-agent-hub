OpenForgeRL: Train Harness-native Agents in Any Environment

arXiv 2026 69.4 method, system

TLDR

OpenForgeRL is an open-source framework for training harness-based agents end-to-end across diverse environments, including GUI and computer-use tasks.

Reasoning

The paper introduces a novel framework that decouples training and inference, enabling RL training on complex harnesses. Its strengths include validation across multiple benchmarks (OSWorld, Mind2Web, WebVoyager) with strong results. Weaknesses: no discussion of limitations or comparison to closed-source systems in the abstract.

Deep Analysis

Innovations

  • OpenForgeRL framework enabling end-to-end reinforcement learning of agents that use complex inference harnesses (e.g., Claude Code, Codex, OpenClaw) in any environment.
  • Lightweight proxy that intercepts harness model calls and records them as training data for standard RL codebases (e.g., veRL), avoiding the need to modify the harness.
  • Kubernetes orchestrator that executes each rollout in an isolated remote container, allowing scalable training on stateful, multi-process harnesses.
  • Decoupling of agent training from inference, letting researchers train and improve agents directly in the real harnesses and environments they are deployed with.
  • Demonstration on diverse agent paradigms, including tool/claw-based agents and multimodal GUI browser- and computer-use agents.

Methodology

OpenForgeRL consists of a proxy that serves the harness's model calls and logs them as training data for a standard RL stack (veRL), and a Kubernetes orchestrator that runs each rollout in a separate container to handle stateful, multi-process harness inference. The framework was validated by training agents on various harnesses (ZeroClaw, OpenClaw, Codex) and environments, using only hundreds to a few thousand tasks per benchmark.

Key Results

OpenForgeClaw attains 31.7 pass^3 and 55.9 pass@3 on ClawEval and 33.7 on QwenClawBench; OpenForgeGUI achieves 37.7 on OSWorld-Verified, 63.0 on Online-Mind2Web, and 72.3 on WebVoyager, outperforming similar-sized open baselines on nearly all benchmarks and matching or surpassing much larger models in GUI settings.

Limitations

  • Critical abilities such as error recovery remain weak even after RL training.
  • Some harnesses are substantially harder to learn than others, implying that harness design heavily influences trainability.
