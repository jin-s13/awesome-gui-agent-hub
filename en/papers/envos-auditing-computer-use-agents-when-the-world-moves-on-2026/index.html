EnvOS: Auditing Computer-Use Agents When the World Moves On : Phenomenon-Based Task Construction, Certification, and Evidence-Based Evaluation

TLDR

EnvOS certifies dynamic task environments for auditing computer-use agents, distinguishing agent errors from environment/grader issues; experiments show reminders to re-check sources improve performance.

Reasoning

The paper's strengths include rigorous environment certification and evidence-based grading that separates agent failures from environment/grader issues; weaknesses are that the abstract is truncated and the scope centers on stale information with proprietary models, limiting generalizability.

Deep Analysis

Innovations

  • EnvOS framework for constructing and certifying computer-use environments that change mid-task, including pre-run checks that changes fire correctly, tasks remain solvable, and graders separate correct from incorrect behavior.
  • Evidence-based post-run auditing that uses separate code to re-check grader verdicts from archived evidence.
  • Phenomenon-based task construction for stale information, where a value the agent has already seen changes before the agent acts on it.
  • Seed-generated environments with an audited automatic verifier, making environments reusable as verifiable-reward reinforcement learning training candidates.
  • Grading stress-tests using corrupted episodes designed blind from task rules and an externally generated corrupted-episode set.

Methodology

EnvOS certifies changing environments before agent runs by checking that each mid-task change fires correctly, the task remains solvable, and the grader separates correct from incorrect behavior; after each run, separate code re-checks the verdict from archived evidence. The framework is applied to stale-information tasks in clinic booking and insurance-claim approval, using Claude Opus 5 and Claude Sonnet 5 under conditions such as no extra information, reminders to re-check, or showing the updated value. The grader is stress-tested on corrupted episodes designed blind from rules and on an externally generated corrupted set, compared against simple log checks.

Key Results

In clinic booking, Claude Opus 5 succeeded on 0/16 tasks with no extra information, 2/16 when reminded to re-check, and 15/16 when the updated value was shown, with a significant gain over the reminder after correcting for all tests (p = 0.00293). In insurance-claim approval, Opus 5 re-checked on its own and succeeded on 10/10, while Claude Sonnet 5 rose from 1/10 to 9/10 when the current policy was shown again, significant in its pre-registered test but not after correcting for all tests; grader stress-testing accepted none of 26 blind corrupted episodes as clean and caught 25 of 39 externally generated corrupted episodes, versus 4 for simple log checks.

Limitations

  • The demonstration is limited to stale-information tasks in clinic booking and insurance-claim approval domains.
  • Claude Sonnet 5's gain from showing the current policy was significant only in the pre-registered test, not after correcting for all tests.
  • On the externally generated corrupted episode set, the EnvOS pipeline caught 25 of 39 episodes rather than all corrupted episodes.
