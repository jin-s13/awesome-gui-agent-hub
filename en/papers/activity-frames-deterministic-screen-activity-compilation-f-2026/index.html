Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay

arXiv 2026 55.5 method

TLDR

Presents a deterministic pipeline to compile screen activity into agent memory, reducing data size and improving question-answering accuracy over LLM summaries, with real-world evaluation.

Reasoning

Strengths: novel approach to agent memory using deterministic compilation, real-world evaluation with large corpus, and cost analysis. Weaknesses: limited to a single user's data, potential generalizability issues, and no comparison to other memory methods.

Deep Analysis

Innovations

  • Deterministic, zero-model pipeline that compiles passively captured screen activity into typed, bounded activity frames with evidence pointers, yielding byte-identical, cacheable, and mechanically auditable agent memory.
  • Activity frames as a compact, replayable agent memory format that enables deterministic replay without model tokens, demonstrated live on a guard-matched hit.
  • Demand-side cost instrument that measures Routine Overhead Ratio R and routine recurrence h from pre-delegation human activity, providing first measured values for these parameters.

Methodology

The compiler passively captures local screen activity, deterministically segments it into typed activity frames (episodes with application, site, timing, input volume, and pointers to raw rows), without any model in the loop. A single-user corpus of 128,756 frames across 51 active days is used to evaluate compression ratio, processing latency, and question-answering accuracy against an independent oracle, comparing the compiled frames to LLM-generated summaries. The same frames are used to compute the Routine Overhead Ratio R and routine recurrence h from human activity patterns.

Key Results

The compiler reduces a day of raw capture to a prompt-ready context block 86× smaller in 68 ms, and an agent reading that block answers questions about the day at 98.4% accuracy (Wilson 95% CI 91.7–99.7%) versus 66–80% for LLM summaries. First measured Routine Overhead Ratio R is 60–343×, delegable recurrence is 9.0% in-sample and 7.7% out-of-sample, with a realistic all-fleet token ceiling near 8%.

Limitations

  • Evaluation is based on a single professional's single-user corpus, limiting generalizability to multi-user or diverse usage patterns.
  • Accuracy is measured only on question-answering about the day, not on broader agent task performance.
  • Routine Overhead Ratio R is a modeled upper bound, not a directly measured value, and may not reflect all deployment costs.
  • Passive screen capture may miss non-screen activities or interactions that are not visible in the capture stream.
