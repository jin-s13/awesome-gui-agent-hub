Deep Analysis

Innovations

  • Proposes that LLM web agents can learn simple environment observations at test time to address performance collapse in complex real-world settings.
  • Introduces trial steps that enable agents to decompose a complex environment observation into sub-modules.
  • Implements a label-free learning method, Test-Time Environment Decomposition (TTED), that adapts agent behaviors using experience during inference.
  • Provides key insights into the design of the label-free learning algorithm for environment decomposition.

Methodology

The method introduces trial steps for LLM web agents to decompose complex environment observations into sub-modules. It uses a label-free learning algorithm, Test-Time Environment Decomposition (TTED), to adapt agent behaviors with experience during inference. The framework is evaluated on both synthetic and realistic benchmarks.

Key Results

Experience gains acquired in simpler sub-environments can be composed to improve performance in the full environment, and test-time training on sub-environments significantly enhances compositional generalization in real-world web automation tasks.
