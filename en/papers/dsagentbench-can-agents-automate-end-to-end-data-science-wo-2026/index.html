Deep Analysis

Innovations

  • First benchmark to evaluate agents on complete end-to-end data-science workflows inside real computer environments
  • Deterministic evaluator that verifies analytical correctness, visual outputs, and model performance beyond code-only execution
  • 275 diverse tasks covering the entire data-science life-cycle, requiring grounding in intermediate outputs and coordinated tool use

Methodology

We constructed DSAgentBench, a benchmark of 275 tasks spanning the full data-science life-cycle, each requiring grounding in intermediate outputs and coordinated use of tools like notebooks, IDEs, and terminals. We evaluated 15 closed- and open-source agents using a deterministic evaluator that checks analytical correctness, visual outputs, and model performance.

Key Results

The strongest agent, Claude-4.6-Sonnet, achieved only 56.70% task success, while all open-source agents remained below 1%, frequently failing at tool orchestration, OS grounding, and multi-step reasoning.
