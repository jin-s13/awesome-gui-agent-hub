Deep Analysis

Innovations

  • Introduces OpenDS, a task for evaluating multi-step deep search in the live, open Web, requiring autonomous search, browser interaction, and evidence integration.
  • Constructs OpenDS-World, a benchmark of 200 human-verified tasks spanning diverse information modalities, heterogeneous file formats, and interactive access requirements.
  • Provides a unified tool environment and execution protocol for systematically evaluating frontier models on autonomous deep search.

Methodology

The paper formulates the OpenDS task, in which agents must autonomously explore the live Web, discover and connect evidence from multiple independent sources via search, browser interaction, and evidence processing, and produce a unique factual answer. It introduces OpenDS-World, a benchmark of 200 human-verified tasks covering diverse modalities, file formats, and access conditions. Twelve frontier models are evaluated under a unified tool environment and execution protocol, with human evaluation across 1,000 independent attempts.

Key Results

The best-performing model achieves 39.0% accuracy, while human evaluation across 1,000 independent attempts yields 21.1% accuracy. Analyses reveal substantial differences in tool usage, search cost, termination behavior, and failure recovery across models.

Limitations

  • Tool coordination remains a persistent challenge for agents.
  • Long-horizon search management remains a persistent challenge for agents.
