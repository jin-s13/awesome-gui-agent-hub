RiskChainBench: A Benchmark for Obfuscated Platform Message Restoration and Evidence-Grounded Web Investigation

arXiv 2026 48.1 method

TLDR

RiskChainBench pairs obfuscated message restoration with web investigation, evaluating VLM-driven web agents on evidence-grounded risk reporting across ten models.

Reasoning

The benchmark design is strong, pairing restoration and web investigation with separate scoring and human labels, enabling nuanced analysis. However, the web environments are local and synthetic rather than live, and high execution failure rates may limit real-world generalizability.

Deep Analysis

Innovations

  • Introduces RiskChainBench, pairing 3,600 synthetic token-text restoration inputs from 600 source sessions with 600 human-labeled local web environments.
  • Unifies obfuscated platform message restoration with downstream evidence-grounded web investigation in a single benchmark, addressing the gap left by evaluating obfuscated text and risky webpages separately.
  • Uses a two-stage protocol in which the same underlying model restores message, operational intent, and destination, then acts as a VLM-driven web agent to produce an evidence-cited risk report.
  • Scores restoration and correct-routing web investigation separately and composes them offline by using the frozen primary-entry prediction as a gate to the Task 2 result.
  • Employs human labels for task correctness plus a fixed multimodal evidence judge assessing faithfulness, sufficiency, completeness, and consistency.
  • Releases the benchmark, protocol, and resettable local sandbox.

Methodology

RiskChainBench pairs 3,600 synthetic token-text restoration inputs from 600 source sessions with 600 corresponding human-labeled local web environments. A model first restores the obfuscated message, operational intent, and destination; the same underlying model then acts as a VLM-driven web agent that investigates the correctly associated website and produces a frozen, evidence-cited risk report without message-side semantics or domain-reputation cues. Restoration and correct-routing web investigation are scored separately and composed offline by applying the frozen primary-entry prediction as a gate to the same Task 2 result, with human labels determining task correctness and a fixed multimodal evidence judge scoring faithfulness, sufficiency, completeness, and consistency across ten models.

Key Results

Across ten models, Entry Top-1 ranges from 35.2% to 95.2% and web decision accuracy ranges from 26.3% to 62.8%. Leading systems differ across entry recovery, full reconstruction, website decisions, and fine-grained typing; execution failures account for 31.9% of web runs, while post-decision type errors account for only 0.9%.

Limitations

  • Execution failures account for 31.9% of web runs, identifying stable exploration and risk judgment as the principal bottlenecks.
  • Leading systems differ across entry recovery, full reconstruction, website decisions, and fine-grained typing, indicating no single evaluated model is dominant across all tasks.
