Deep Analysis

Innovations

  • Model-agnostic harness that converts artifact-validated GUI trajectories into standardized, parameter-controlled callable memories rather than unstructured experience records.
  • MCP-style memory representation storing task-intent keys, application and state preconditions, flexible input parameters, GUI evidence, validation provenance, and lifecycle state.
  • Image-based target-reaiming algorithm that treats stored coordinates as visual evidence, matches remembered GUI targets against the current screen, and emits corrected operation coordinates before execution.
  • Replay mechanism that rebinds only declared modifiable inputs and rejects ambiguous or incompatible steps to bound grounding repair or fresh planning.

Methodology

EchoPath converts validated GUI trajectories into callable memories with task-intent keys, preconditions, parameters, GUI evidence, provenance, and lifecycle state. During replay, it checks deterministic applicability, rebinds declared inputs, and uses image-based target-reaiming to correct stored coordinates against the current screen. The approach was evaluated on real computer-use tasks, with median token cost and execution time as metrics.

Key Results

In real computer-use tasks, EchoPath reduced median token cost by more than 90% and median execution time by about 60%.

Limitations

  • EchoPath only invokes memories when they can be deterministically replayed in the current runtime, and it rejects ambiguous or incompatible steps, diverting them to bounded grounding repair or fresh planning.
