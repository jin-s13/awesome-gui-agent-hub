Deep Analysis

Innovations

  • Compiles specifications into stateful applications with tasks graded against the application's own database (grounded verifier).
  • Co-evolution loop that uses every graded rollout twice: to repair the environment, tasks, and verifier, and as training signal for the model.
  • Emphasizes three environment properties: behavioral depth, targeting agent failures, and co-improvement alongside the model.
  • Unified environments serve as reinforcement-learning setups with a reward combining the grounded verifier and a dense per-step judge.

Methodology

Echoverse generates synthetic, stateful applications from specifications, with tasks verified by database queries. A co-evolution loop reads agent rollouts to repair environments and provide training signal. A 9B model is trained on twelve such environments and evaluated on fourteen splits, also using RL with a combined reward.

Key Results

A 9B model trained on Echoverse environments improves from 36.5% to 67.1% across 14 evaluation splits, within 14 points of the frontier teacher. Deep environments raise live-site accuracy (80.0→85.0, 48.0→65.0), while shallow ones drop it (80.0→75.0). Repairing a single environment lifts the model from 16.2% to 38.5%. RL with the combined reward boosts held-out score from 58.8% to 68.0%.

Limitations

  • Trained model still lags 14 points behind the frontier teacher model.
  • Shallow environments can degrade live-site accuracy below the base model.
