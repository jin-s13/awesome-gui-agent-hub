WebAnything: From the Wild Web to Scalable Agent Environments

arXiv 2026 54.1 method

TLDR

WebAnything automatically reconstructs source-grounded, resettable web environments from real URLs to enable scalable web agent training and evaluation, with 244 artifacts and improved task success.

Reasoning

The paper's strength is a fully automated pipeline for building diverse, reusable web environments with verification and repair, plus empirical gains in agent performance. Weaknesses include a web-only scope and reliance on initial setup/authorization, with limited generalizability to other GUI or OS domains.

Deep Analysis

Innovations

  • Fully automated reconstruction of source-grounded, reusable web environments from real URLs without per-site manual implementation or repair after initial setup and authorization.
  • Explorer-Builder pipeline that collects browser-observable structures, resources, and interaction outcomes, paired with an independent verifier that checks frozen candidates and guides local repair or targeted source recapture.
  • Scalable creation of 244 website artifacts across 14 application domains and 53 categories, supporting 12,984 executed and accepted agent tasks.
  • Demonstrated use of the generated environments for fine-tuning: 5,856 interaction trajectories improve Qwen3.5-9B across REAL, Odysseys-Easy, and WebArena-Verified benchmarks.

Methodology

WebAnything reconstructs source-grounded reusable web environments from real URLs. An Explorer-Builder collects browser-observable structures, resources, and interaction outcomes, while an independent verifier checks frozen candidates and guides local repair or targeted source recapture. The authors create 244 website artifacts across 14 domains and 53 categories, compare fidelity against WebHarbor via blind audit, and fine-tune Qwen3.5-9B on 5,856 interaction trajectories for evaluation on REAL, Odysseys-Easy, and WebArena-Verified under a fixed harness.

Key Results

WebAnything achieves higher aggregate scores than WebHarbor on three fidelity metrics, with 12 wins, two ties, and no losses in a blind audit. Fine-tuning Qwen3.5-9B on 5,856 interaction trajectories improves REAL success by 9.9 percentage points, Odysseys-Easy Rubric Avg and Task Avg by 6.25 and 6.32 percentage points, and WebArena-Verified Overall success by 13.33 percentage points.

Limitations

  • Requires initial setup and authorization per real URL, even though no per-site manual implementation or repair is needed afterward.
  • Fine-tuning gains are reported under a fixed harness, so the improvements may be specific to that evaluation setup.
