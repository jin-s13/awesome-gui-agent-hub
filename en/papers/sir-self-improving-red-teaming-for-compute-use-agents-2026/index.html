Deep Analysis

Innovations

  • SIR: a black-box indirect prompt injection attack that composes stealthy injections from a small library of reusable plain-language principles.
  • Iterative feedback loop that diagnoses failed victim trajectories and distills bypasses into new named strategies reapplied across tasks.
  • Operating-system-level red-teaming of computer use agents scored by a fully deterministic oracle using filesystem, service, and permission state rather than an LLM judge.
  • Cross-architecture transfer of discovered principles without additional feedback.

Methodology

SIR composes stealthy indirect prompt injection attacks from reusable plain-language principles and refines them via an iterative feedback loop that diagnoses failed trajectories and distills bypass strategies. It targets computer use agents at the operating system level and is evaluated on three frontier CUAs, scoring attacks with deterministic filesystem, service, and permission state checks rather than an LLM judge. Attack success is compared against a hand-written injection baseline while also checking benign task completion.

Key Results

SIR raised attack success rate from 4% to 24% on Claude Opus 4.8 and from 0% to 28% on Gemini 3.5 Flash, while the benign task still completed. Principles discovered against one model transferred to a different architecture with no additional feedback.
