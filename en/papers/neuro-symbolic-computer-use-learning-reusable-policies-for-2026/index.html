Deep Analysis

Innovations

  • Neuro-symbolic computer use: recurring workflows are executed by learned policies rather than re-planned by an agent each run, combining executable code for stable decisions with neural models for observation-dependent decisions.
  • Neuro-symbolic policy iteration: starting from one agent trajectory, the policy is executed, failures are diagnosed with task-completion and step-level judges, and code is revised by a coding model informed by an agent's continuation from the failure point, without access to the benchmark evaluator.
  • Reusable policy learning via generated parameter and initial-state variants, plus a pre-action verifier that guards each state-mutating step at deployment.

Methodology

The method learns a policy from one agent trajectory, fixing stable workflow decisions in executable code and delegating observation-dependent decisions such as grounding and state checks to neural models. Policy iteration executes the policy, diagnoses failures with task-completion and step-level judges, and revises code using a coding model guided by an agent's continuation from the failure point, without benchmark evaluator access. It iterates over generated parameter and initial-state variants and uses a pre-action verifier at deployment, with evaluation on OSWorld-Verified and ScienceBoard.

Key Results

Learned policies achieve the highest Pass^3 of all methods in all four OSWorld-Verified and ScienceBoard settings, 3.6-15.8 points above the base agent, while cutting per-run cost by 15-217x and latency by 3.4-5.1x. On OSWorld-Verified, policies built only on variants transfer to held-out original tasks, exceeding AutoRPA by 8.6-17.5 points in Pass^3.
