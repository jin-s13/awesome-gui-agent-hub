Deep Analysis

Innovations

  • Task Model Induction (TMI) framework that discovers latent tasks and disentangles concurrent, interleaved activity from unconstrained computer-use traces without requiring predefined task boundaries.
  • Induction of a hierarchical task model that pairs a recursive goal decomposition (objective model) with a procedure model capturing the control flow of execution.
  • Derivation of symbolic, auditable, and reusable task models from low-level screenshots and mouse/keyboard actions.

Methodology

TMI takes passively recorded computer-use traces (screenshots, mouse/keyboard actions) and first discovers latent tasks while disentangling interleaved goals. It then induces a hierarchical task model consisting of a recursive goal decomposition and a procedure model of control flow. Evaluation uses controlled human and agent trajectories, measuring intrinsic task recovery agreement and step reconstruction, and extrinsic improvement on held-out task accuracy.

Key Results

On controlled trajectories, TMI recovers interleaved tasks with 0.974 agreement against ground-truth groupings and reconstructs 74.9% of observed execution steps, far surpassing the strongest workflow induction baseline. Extrinsically, skills derived from TMI's task models improve held-out task accuracy by 30.0% over the strongest baseline.
