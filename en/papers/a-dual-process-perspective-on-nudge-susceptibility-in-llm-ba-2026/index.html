Deep Analysis

Innovations

  • Applies Dual-Process Theory to distinguish automatic (Type 1) and reflective (Type 2) nudge susceptibility in LLM-based GUI agents rather than in textual outputs alone.
  • Shows that reasoning configuration moderates nudge susceptibility in opposing directions: reducing susceptibility to automatic default nudges while increasing susceptibility to reflective social influence nudges.
  • Demonstrates that extensive reasoning does not make agents more robust but redirects the route through which choice architecture takes effect.
  • Provides exploratory evidence that this redirection is systematically structured by model scale.
  • Frames interface design as a governance concern for organizations delegating decisions to autonomous agents.

Methodology

The study uses a randomized online shopping experiment with 3,600 LLM-based GUI agents and 21,600 total simulations across six frontier models from three providers. Agents perceive interfaces and execute decisions under automatic (Type 1) and reflective (Type 2) digital nudge conditions, while reasoning configuration is varied to assess moderation. The design compares nudge susceptibility across nudge types and reasoning settings using behavioral simulation outcomes.

Key Results

Agents were vulnerable to both automatic and reflective nudges. Reasoning configuration moderated susceptibility in opposing directions, reducing default-nudge effects while increasing social-influence-nudge effects, and exploratory analysis indicated this redirection was structured by model scale.

Limitations

  • The model-scale redirection finding is explicitly exploratory rather than confirmatory.
