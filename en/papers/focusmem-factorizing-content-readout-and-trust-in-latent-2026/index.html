Deep Analysis

Innovations

  • Role-aware content basis that separates episodic memory for reusable experience and working memory for task progress within latent memory
  • State-conditioned readout that generates a decision-specific view of the same stored evidence
  • Lightweight trust gate that suppresses memory blocks irrelevant to the current step
  • Training memory components with a frozen GUI policy, enabling integration without altering the base agent

Methodology

FocusMem compresses multimodal GUI trajectories into continuous latent tokens and factorizes memory into a content basis, readout, and trust gate. The role-aware content basis distinguishes episodic and working memory, while the readout and trust gate modulate information per decision step. The memory components are trained with next-action supervision while the GUI policy remains frozen, evaluated on five GUI-agent benchmarks against fixed-memory baselines and prior latent memory adaptations.

Key Results

FocusMem consistently outperforms action-only fixed-memory and prior latent memory baselines across five GUI-agent benchmarks. Analyses show complementary information preservation, increased robustness of state-conditioned readout with longer context, and harm reduction from irrelevant episodic evidence via the trust gate.
