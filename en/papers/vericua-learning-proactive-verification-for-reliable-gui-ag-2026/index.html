VeriCUA: Learning Proactive Verification for Reliable GUI Agent Rewards

arXiv 2026 59.7 method

TLDR

Introduces VeriCUA, a trainable proactive reward agent that learns when and what to verify in GUI environments via online RL, improving reward agreement across OSWorld, MobileWorld, and WebArena-Verified.

Reasoning

The paper addresses a clear limitation in reward verification for GUI agents, proposing a learning-based verification strategy that outperforms prompted foundation models on multiple benchmarks. Strengths include cross-benchmark evaluation and cost-aware optimization; weaknesses include dependence on single verification attempts and limited detail in the abstract about actual experimental robustness.

Deep Analysis

Innovations

  • Introduces VeriCUA, a proactive reward agent that learns its verification strategy from single execution attempts despite the inability to faithfully replicate the Actor's terminal state during training.
  • Decouples verification into a trainable Judge that decides what to check and when to stop, and a frozen Probe that executes checks in the live GUI environment.
  • Uses online reinforcement learning to optimize the Judge for both verdict correctness and efficient Probe use, with returns normalized across terminal states.
  • Identifies verification strategy rather than verifier scale as the key to reliable GUI rewards, showing prompted Judges plateau at 68%-70% macro-average agreement.

Methodology

VeriCUA consists of a trainable Judge that decides what to check and when to stop, and a frozen Probe that executes checks in the live environment. It is trained using online reinforcement learning on OSWorld only, optimizing for verdict correctness and efficient Probe use with returns normalized across terminal states. Evaluated without further training on MobileWorld and WebArena-Verified, it is compared against prompted Judges ranging from 4B to GPT-5.4 using reward agreement, Probe token cost, and downstream Actor task success.

Key Results

Trained only on OSWorld, VeriCUA achieves the highest reward agreement across OSWorld, MobileWorld, and WebArena-Verified, and lies on the agreement-cost Pareto frontier among proactive verifiers. It surpasses few-shot GPT-5.4 by 5.36 points while using 47.6%-59.8% fewer Probe tokens, a 1B VeriCUA exceeds every prompted Judge, and as an Actor RL reward it improves task success by 3.21 points overall and 5.40 points on held-out multi-application tasks.

Limitations

  • Learning from execution is constrained because the Actor's terminal state cannot be faithfully replicated during training, allowing only one verification attempt per state.
  • Training is performed only on OSWorld, so broader training diversity and generalization beyond zero-shot evaluation on MobileWorld and WebArena-Verified are not fully characterized.
