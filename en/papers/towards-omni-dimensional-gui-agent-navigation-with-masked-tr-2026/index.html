Deep Analysis

Innovations

  • Proposes MaP (Masked Trajectory Prediction), a unified framework that harmonizes divergent GUI navigation tasks.
  • Models multi-turn GUI interactions as a trajectory and uses component masking and prediction objectives to replace task-specific marginal distribution optimization with a consistent objective.
  • Introduces a role-aware adapter learning module that dynamically routes tokens to specialized representation spaces to handle cross-task data heterogeneity.

Methodology

MaP models multi-turn GUI interactions as trajectories and defines training objectives through component masking and prediction, shifting optimization from task-specific marginal distributions to a unified objective. A role-aware adapter learning module routes each token to a specialized representation space to address data heterogeneity across navigation tasks. The approach is evaluated on five representative GUI navigation benchmarks and compared against direct mixture training.

Key Results

MaP effectively mitigates gradient conflicts and significantly outperforms direct mixture training across five representative GUI navigation benchmarks.
