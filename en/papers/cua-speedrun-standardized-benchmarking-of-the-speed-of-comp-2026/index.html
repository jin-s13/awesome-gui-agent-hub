Deep Analysis

Innovations

  • Proposes cua-speedrun, a standardized benchmark infrastructure and task set focused on evaluating the speed and efficiency of computer-use agents.
  • Introduces a uniform virtual machine setup and execution pipeline to reduce confounding factors in speed evaluation.
  • Provides a common agent interface that allows a single agent implementation to operate seamlessly across different CUA benchmarks.
  • Shows that evaluation task sets for most CUA benchmarks can be reduced without degrading statistical power, enabling more efficient benchmarking.

Methodology

cua-speedrun uses a uniform virtual machine setup, execution pipeline, and common agent interface to evaluate computer-use agents across four different CUA benchmarks. The study examines how reasoning effort, agent harnesses, and environment latency affect performance, speed, and cost. It also analyzes reductions in evaluation task set size while preserving statistical power.

Key Results

No single model family is optimal for performance, speed, and cost simultaneously, and none of the open-weight models are on the frontier. For some models, increasing reasoning effort speeds up task completion, while faster environment input-output can slow down overall completion time; most CUA benchmark task sets can also be reduced without losing statistical power.
